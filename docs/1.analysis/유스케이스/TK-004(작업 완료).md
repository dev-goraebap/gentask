# TK-004 작업 완료

- **목표:** 완료한 작업을 목록이 완료된 작업로 갖게 한다.
- **주 액터:** 사용자
- **지원 액터:** 없음
- **트리거:** 그 작업을 끝냈다.

## 기본 흐름 (Basic Flow)

1. 사용자가 완료한 작업을 고른다.
2. 사용자가 이 일을 완료했다고 한다.
3. 시스템이 작업을 완료 상태로 바꾼다.
4. 시스템이 완료되지 않은 작업 목록에서 그것을 빼 보여 준다.
5. 사용자가 남은 일만 보고 있음을 확인한다.

## 대체 흐름 (Alternate Flows)

### A1 이미 완료된 작업이다

- **시작 조건:** 2단계에서 그 작업이 이미 완료 상태다.
- **처리 절차:**
  1. 시스템이 상태를 바꾸지 않는다.
  2. **별도 성공 출구.** 그 작업은 완료된 작업로 남는다.

### A2 완료를 취소한다

- **시작 조건:** 완료된 작업로 표시된 작업에 대해, 사용자가 아직 끝내지 않았다고 한다. 이 유스케이스가 완료된 뒤 다시 들어오는 길이다.
- **처리 절차:**
  1. 사용자가 완료를 취소한다고 한다.
  2. 시스템이 완료 상태를 떼고, 완료되지 않은 작업 목록에 다시 보여 준다.
  3. **별도 성공 출구.** 그 작업은 완료되지 않은 작업이다.

### A3 고르려 한 작업이 없다

- **시작 조건:** 1단계에서 고르려 한 작업이 없다.
- **처리 절차:**
  1. 시스템이 그 작업을 보여 주지 않는다.
  2. **실패로 종료.**

### A4 갱신에 실패한다

- **시작 조건:** 3단계에서 시스템이 상태를 바꾸지 못한다.
- **처리 절차:**
  1. 시스템이 바꾸지 못했음을 알린다.
  2. **실패로 종료.** 작업은 완료 전과 같다.

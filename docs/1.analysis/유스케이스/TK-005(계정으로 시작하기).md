# TK-005 계정으로 시작하기

- **목표:** 내 작업이 내 계정에 묶여, 어느 자리에서든 내 목록으로 돌아온다.
- **주 액터:** 사용자
- **지원 액터:** 없음
- **트리거:** 시스템을 처음 쓰려 하거나, 로그인이 풀린 채 돌아왔다.

로그인 자체는 하위 기능이라 유스케이스로 올리지 않는다([작성지침](../작성지침.md) 3절). 여기서는 "내 목록으로 돌아온다"는 목표 아래 등록·로그인·로그아웃을 한 흐름 집합으로 묶는다.

## 기본 흐름 (Basic Flow)

돌아온 사용자가 가장 잦은 경로다.

1. 사용자가 이메일과 비밀번호를 제공한다.
2. 시스템이 자격을 검증한다.
3. 시스템이 로그인 상태를 만들고 유지한다.
4. 사용자가 자신의 작업 목록을 본다.

## 대체 흐름 (Alternate Flows)

### A1 계정이 없어 등록한다

- **시작 조건:** 1단계 앞, 사용자에게 계정이 없다.
- **처리 절차:**
  1. 사용자가 이메일과 비밀번호를 제공한다.
  2. 시스템이 이메일이 쓰이지 않았음과 형식을 검증한다.
  3. 시스템이 계정을 만들고 곧바로 로그인 상태를 만든다.
  4. **기본 흐름 4로 복귀.**

이메일 소유 확인(메일 인증)은 두지 않는다. 넣게 되면 이 흐름의 2단계와 3단계 사이에 들어온다.

### A2 자격이 맞지 않는다

- **시작 조건:** 2단계에서 자격이 검증되지 않는다.
- **처리 절차:**
  1. 시스템이 이메일과 비밀번호가 맞지 않음을 알린다. 어느 쪽이 틀렸는지는 구분하지 않는다.
  2. **기본 흐름 1로 복귀.**

### A3 이미 등록된 이메일이다

- **시작 조건:** A1 의 2단계에서 그 이메일이 이미 쓰이고 있다.
- **처리 절차:**
  1. 시스템이 이미 등록된 이메일임을 알린다.
  2. **기본 흐름 1로 복귀.** 로그인이 그 계정으로 돌아가는 길이다.

### A4 로그아웃한다

- **시작 조건:** 로그인 상태에서, 사용자가 자리를 정리하고 떠나려 한다.
- **처리 절차:**
  1. 시스템이 로그인 상태를 거둔다.
  2. **별도 성공 출구.** 이후 접근은 A5 를 따른다.

### A5 로그인 없이 접근한다

- **시작 조건:** 로그인 상태가 아닌 채 작업 화면에 접근한다.
- **처리 절차:**
  1. 시스템이 작업을 보여 주지 않고 로그인 자리로 안내한다.
  2. **기본 흐름 1로 복귀.**

## 미결

- 비밀번호 재설정: 잊은 비밀번호를 메일로 되찾는 흐름. 메일 발송이 붙을 때 대체 흐름으로 올린다
- 기기(세션) 목록과 개별 로그아웃: 여러 기기에서 쓰기 시작하면 올린다

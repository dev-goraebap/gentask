# TK-002 지금 할 일 보기

- **목표:** 지금 손댈 일을 고른다.
- **주 액터:** 사용자
- **지원 액터:** 없음
- **트리거:** 다음에 손댈 일을 정해야 한다. 또는 일을 하나 마쳤다.

## 기본 흐름 (Basic Flow)

1. 사용자가 목록을 본다.
2. 시스템이 아직 끝나지 않은 할일을 보여 준다.
3. 사용자가 목록을 훑는다.
4. 사용자가 다음에 손댈 할일 하나를 고른다.

## 대체 흐름 (Alternate Flows)

묶음(A1–A4)은 서로 다른 길이지만 같은 목표다. 묶음마다 유스케이스를 두지 않는다.

### A1 끝난 할일만 본다

- **시작 조건:** 1단계 뒤, 사용자가 끝난 일만 보겠다고 한다.
- **처리 절차:**
  1. 시스템이 끝난 할일만 보여 준다.
  2. **기본 흐름 3으로 복귀.**

### A2 오늘 담은 할일만 본다

- **시작 조건:** 1단계 뒤, 사용자가 오늘 담은 일만 보겠다고 한다.
- **처리 절차:**
  1. 시스템이 오늘 담은, 아직 끝나지 않은 할일만 보여 준다.
  2. **기본 흐름 3으로 복귀.**

### A3 중요하다고 표시한 할일만 본다

- **시작 조건:** 1단계 뒤, 사용자가 중요한 일만 보겠다고 한다.
- **처리 절차:**
  1. 시스템이 중요하다고 표시한, 아직 끝나지 않은 할일만 보여 준다.
  2. **기본 흐름 3으로 복귀.**

### A4 기한이 있는 할일만 본다

- **시작 조건:** 1단계 뒤, 사용자가 기한이 있는 일만 보겠다고 한다.
- **처리 절차:**
  1. 시스템이 마감일이 있는, 아직 끝나지 않은 할일만 보여 준다.
  2. **기본 흐름 3으로 복귀.**

### A5 해당하는 할일이 없다

- **시작 조건:** 2단계 또는 A1–A4 뒤, 보여줄 할일이 없다.
- **처리 절차:**
  1. 시스템이 할일이 없음을 알린다.
  2. **별도 성공 출구.** 사용자는 고를 일이 없음을 안다.

### A6 순서를 고른다

- **시작 조건:** 2단계 뒤, 사용자가 다른 순서로 보겠다고 한다.
- **처리 절차:**
  1. 사용자가 기준을 하나 고른다. 기준은 중요도 · 기한 · 오늘 담은 때 · 제목 · 만든 때다.
  2. 시스템이 그 기준으로 끝나지 않은 할일을 다시 늘어놓는다. 기준 값이 없는 할일(기한 없음, 오늘에 담지 않음)은 뒤에 둔다.
  3. 사용자가 같은 기준을 다시 고르면 시스템이 방향을 뒤집는다.
  4. **기본 흐름 3으로 복귀.**

기준을 고르지 않은 상태의 순서는 만든 때이며 최근 것이 앞이다. 순서는 묶음(A1–A4)과 독립이다.

### A7 본 적 없는 묶음을 요청한다

- **시작 조건:** 1단계에서 사용자가 시스템이 모르는 묶음을 보겠다고 한다. 예를 들어 옛 북마크로 들어온다.
- **처리 절차:**
  1. 시스템이 아직 끝나지 않은 할일을 보여 준다.
  2. **기본 흐름 3으로 복귀.**

### A8 (결번)

목록에서 고르는 흐름에서는 없는 할일을 고를 수 없다. 고른 뒤 그 할일이 사라져 있는 경우는 고른 목적지가 갖는다 (TK-003 A8, TK-004 A3).

A2–A4와 A6을 같이 쓰는 것은 경로이다. 새 대체 흐름을 두지 않는다.

## 미결

화면으로 정하지 못한 것이다. 해당 슬라이스에 착수할 때 정한다.

- 하루의 경계: 오늘 담은 일이 비워지는 시각과 시간대 판정 기준
- 끝난 일의 노출: 끝난 할일이 오늘 · 중요 묶음에 남는지. 기한 있는 일(A4)은 끝나지 않은 것만 담기로 했다
- 묶음과 순서의 관계: 고른 순서(A6)가 묶음을 바꿔도 유지되는지
- 중요와 순서의 관계: 중요 표시가 다른 묶음의 순서에 관여하는지

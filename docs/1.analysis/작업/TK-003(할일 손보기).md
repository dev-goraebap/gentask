# TK-003 할일 손보기

- **목표:** 적힌 할일을 지금 아는 것과 같게 만든다.
- **주 액터:** 사용자
- **지원 액터:** 없음
- **트리거:** 제목·메모·기한·표시가 틀렸거나, 이 일은 하지 않기로 했다.

## 기본 흐름 (Basic Flow)

1. 사용자가 손볼 할일을 고른다.
2. 시스템이 그 할일의 현재 내용을 보여 준다.
3. 사용자가 제목을 고친다.
4. 시스템이 제목이 비어 있지 않음을 검증한다.
5. 시스템이 할일을 갱신한다.
6. 사용자가 바뀐 내용을 확인한다.

## 대체 흐름 (Alternate Flows)

기본 흐름 3–5는 제목을 고치는 경우다. 다른 속성은 A2–A5가 같은 자리를 대신하며, 각 속성은 고친 즉시 갱신된다. 선택(A2–A5)은 서로 조합될 수 있다. 조합마다 대체 흐름을 두지 않는다.

### A1 제목이 비어 있다

- **시작 조건:** 4단계에서 제목이 비어 있다.
- **처리 절차:**
  1. 시스템이 제목이 필요함을 알린다.
  2. 사용자가 제목을 다시 고친다.
  3. **기본 흐름 4로 복귀.**
- 사용자가 그만두면 A7로 간다.

### A2 메모를 고친다

- **시작 조건:** 2단계 뒤, 사용자가 메모를 고치겠다고 한다.
- **처리 절차:**
  1. 사용자가 메모를 고친다.
  2. 시스템이 메모를 갱신한다.
  3. **기본 흐름 6으로 복귀.**

### A3 마감일을 고친다

- **시작 조건:** 2단계 뒤, 사용자가 마감일을 고치겠다고 한다.
- **처리 절차:**
  1. 사용자가 마감일을 정하거나 뗀다.
  2. 시스템이 마감일을 갱신한다.
  3. **기본 흐름 6으로 복귀.**

### A4 중요 표시를 바꾼다

- **시작 조건:** 2단계 뒤, 사용자가 중요 표시를 바꾸겠다고 한다.
- **처리 절차:**
  1. 사용자가 중요하다고 하거나 그 표시를 뗀다.
  2. 시스템이 표시를 갱신한다.
  3. **기본 흐름 6으로 복귀.**

### A5 오늘 담기를 바꾼다

- **시작 조건:** 2단계 뒤, 사용자가 오늘 담기를 바꾸겠다고 한다.
- **처리 절차:**
  1. 사용자가 오늘 담거나 오늘에서 뺀다.
  2. 시스템이 담은 상태를 갱신한다.
  3. **기본 흐름 6으로 복귀.**

### A6 이 일은 하지 않기로 한다

- **시작 조건:** 2단계 뒤, 사용자가 이 할일을 버린다고 한다.
- **처리 절차:**
  1. 시스템이 되돌릴 수 없음을 확인받는다.
  2. 사용자가 확인한다.
  3. 시스템이 할일을 목록에서 뺀다.
  4. **별도 성공 출구.** 그 할일은 목록에 없다.
- 사용자가 확인하지 않으면 **기본 흐름 2로 복귀.**

### A7 손보기를 그만둔다

- **시작 조건:** 1–4단계 어디서든, 사용자가 그만둔다.
- **처리 절차:**
  1. 시스템이 고치던 제목을 반영하지 않는다.
  2. **실패로 종료.** 제목은 고치기 전과 같다. 그 전에 A2–A5로 갱신한 값은 이미 반영되어 있다.

### A8 고르려 한 할일이 없다

- **시작 조건:** 1단계에서 고르려 한 할일이 없다.
- **처리 절차:**
  1. 시스템이 그 할일을 보여 주지 않는다.
  2. **실패로 종료.**

### A9 갱신에 실패한다

- **시작 조건:** 5단계 또는 A2–A5에서 시스템이 갱신하지 못한다.
- **처리 절차:**
  1. 시스템이 바꾸지 못했음을 알린다.
  2. **실패로 종료.** 할일은 이전 값이다.

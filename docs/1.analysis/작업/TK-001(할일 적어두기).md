# TK-001 할일 적어두기

- **목표:** 떠오른 일을 목록에 남겨, 기억에 의존하지 않는다.
- **주 액터:** 사용자
- **지원 액터:** 없음
- **트리거:** 할 일이 떠올랐다.

## 기본 흐름 (Basic Flow)

1. 사용자가 새 할일을 적겠다고 한다.
2. 시스템이 적을 수 있게 한다.
3. 사용자가 제목을 적는다.
4. 시스템이 제목이 비어 있지 않음을 검증한다.
5. 시스템이 할일을 목록에 넣는다.
6. 사용자가 목록에서 방금 적은 할일을 확인한다.

## 대체 흐름 (Alternate Flows)

선택(A2–A4)은 서로 조합될 수 있다. 조합마다 대체 흐름을 두지 않는다.

### A1 제목이 비어 있다

- **시작 조건:** 4단계에서 제목이 비어 있다.
- **처리 절차:**
  1. 시스템이 제목이 필요함을 알린다.
  2. 사용자가 제목을 다시 적는다.
  3. **기본 흐름 4로 복귀.**
- 사용자가 적기를 그만두면 A5로 간다.

### A2 마감일을 붙인다

- **시작 조건:** 3단계 뒤, 사용자가 마감일을 붙이겠다고 한다.
- **처리 절차:**
  1. 사용자가 마감일을 정한다.
  2. 시스템이 마감일을 할일에 붙인다.
  3. **기본 흐름 4로 복귀.**

### A3 미리 알림을 붙인다

- **시작 조건:** 3단계 뒤, 사용자가 미리 알림을 붙이겠다고 한다.
- 처리 절차는 착수할 때 쓴다. 알림을 시스템이 직접 울릴지 바깥(지원 액터)에 맡길지가 먼저 정해져야 한다.

마감일(A2)과 함께 붙일 수는 있다. 그때는 A2와 A3를 잇달아 지나는 경로이지, 새 대체 흐름이 아니다.

### A4 반복 주기를 붙인다

- **시작 조건:** 3단계 뒤, 사용자가 반복 주기를 붙이겠다고 한다.
- 처리 절차는 착수할 때 쓴다. 마친 뒤 다음 회차가 어떻게 생기는지(TK-004 와의 접점)가 먼저 정해져야 한다.

### A5 적기를 그만둔다

- **시작 조건:** 1–4단계 어디서든, 사용자가 적기를 그만둔다.
- **처리 절차:**
  1. 시스템이 할일을 목록에 넣지 않는다.
  2. **실패로 종료.** 기존 목록은 그대로다.

### A6 등록에 실패한다

- **시작 조건:** 5단계에서 시스템이 할일을 목록에 넣지 못한다.
- **처리 절차:**
  1. 시스템이 남기지 못했음을 알린다.
  2. 사용자가 다시 적겠다고 하면 **기본 흐름 5로 복귀.**
  3. 사용자가 그만두면 A5로 간다.

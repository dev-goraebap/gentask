# 대체흐름 구체화 예제 (TK-001)

초안의 이름 목록을 처리 절차까지 푼 것입니다. 선택(A2–A4)은 서로 조합될 수 있고, 조합마다 대체 흐름을 두지 않습니다.

### A1 제목이 비어 있다

- **시작 조건:** 4단계에서 제목이 비어 있다.
- **처리 절차:**
  1. 시스템이 제목이 필요함을 알린다.
  2. 사용자가 제목을 다시 적는다.
  3. **기본 흐름 4로 복귀.**
- 사용자가 적기를 그만두면 A5로 간다.

### A2 마감일을 붙인다

- **시작 조건:** 3단계 뒤, 사용자가 마감일을 붙이겠다고 한다.
- **처리 절차:**
  1. 사용자가 마감일을 정한다.
  2. 시스템이 마감일을 할일에 붙인다.
  3. **기본 흐름 4로 복귀.**

### A3 미리 알림을 붙인다

- **시작 조건:** 3단계 뒤, 사용자가 미리 알림을 붙이겠다고 한다.
- **처리 절차:**
  1. 사용자가 알릴 시점을 정한다.
  2. 시스템이 미리 알림을 할일에 붙인다.
  3. **기본 흐름 4로 복귀.**

마감일(A2)과 함께 붙일 수는 있다. 그때는 A2와 A3를 잇달아 지나는 경로이지, 새 대체 흐름이 아니다.

### A4 반복 주기를 붙인다

- **시작 조건:** 3단계 뒤, 사용자가 반복 주기를 붙이겠다고 한다.
- **처리 절차:**
  1. 사용자가 반복 주기를 정한다.
  2. 시스템이 반복 주기를 할일에 붙인다.
  3. **기본 흐름 4로 복귀.**

### A5 적기를 그만둔다

- **시작 조건:** 1–4단계 어디서든, 사용자가 적기를 그만둔다.
- **처리 절차:**
  1. 시스템이 할일을 목록에 넣지 않는다.
  2. **실패로 종료.** 기존 목록은 그대로다.

### A6 등록에 실패한다

- **시작 조건:** 5단계에서 시스템이 할일을 목록에 넣지 못한다.
- **처리 절차:**
  1. 시스템이 남기지 못했음을 알린다.
  2. 사용자가 다시 적겠다고 하면 **기본 흐름 5로 복귀.**
  3. 사용자가 그만두면 A5로 간다.

`A`는 Alternate의 관례입니다. 원문은 `Alt1`을 씁니다. 슬라이스에서 `BF, A3`처럼 가리키려고 붙입니다.

이 흐름에서 슬라이스가 갈라지는 모양은 [슬라이스 예제](./슬라이스 예제.md)입니다.

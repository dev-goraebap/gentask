# 작성초안 예제 (TK-001)

이름과 불릿만 있는 단계입니다. 대체 흐름은 조건 이름만 적습니다.

```text
# TK-001 할일 적어두기

- **목표:** 떠오른 일을 목록에 남겨, 기억에 의존하지 않는다.
- **주 액터:** 사용자
- **지원 액터:** 없음
- **트리거:** 할 일이 떠올랐다.

## 기본 흐름 (Basic Flow)

1. 사용자가 새 할일을 적겠다고 한다.
2. 시스템이 적을 수 있게 한다.
3. 사용자가 제목을 적는다.
4. 시스템이 제목이 비어 있지 않음을 검증한다.
5. 시스템이 할일을 목록에 넣는다.
6. 사용자가 목록에서 방금 적은 할일을 확인한다.

## 대체 흐름 (Alternate Flows)

- 제목이 비어 있다
- 마감일을 붙인다
- 미리 알림을 붙인다
- 반복 주기를 붙인다
- 적기를 그만둔다
- 등록에 실패한다
```

목표는 이름을 반복하지 않습니다. 1단계는 `적어두고 싶다`가 아니라 트리거 다음의 첫 행위입니다. 풀어 쓴 대체 흐름은 [대체흐름 구체화 예제](./대체흐름 구체화 예제.md)입니다.

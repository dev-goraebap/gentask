# 결정-0002: 프로젝트 이름을 스택 중립적인 "웹앱 개발키트"로 변경

- 상태: 승인됨
- 날짜: 2026-07-23

## 맥락

초기 이름은 "앵귤러&스프링부트 개발키트"였다. 논의를 거치며 이 프로젝트의 핵심 자산이
스택 코드가 아니라 프로세스 체계 + 기능 명세 + 설계 결정임이 명확해졌다.
스택에 묶인 이름은 기술 스택이 바뀔 때 정체성과 충돌한다.

## 검토한 대안

- 스택 이름 유지: 스택이 바뀌면 별도 프로젝트로 분리한다는 초기 방침과는 일치하나, 명세·프로세스 자산이 스택보다 오래 산다는 점과 어긋남
- 은유형 이름(디딤돌, 주춧돌, 모루): 독특하나 서술성이 떨어짐
- 서술형 이름(웹앱 개발키트): 평범하지만 정체를 정확히 설명

## 결정

- 프로젝트 이름: **웹앱 개발키트** (GitHub 저장소명: `webapp-devkit`)
- 스택 메이저 교체(Angular/Spring 이탈)도 별도 프로젝트가 아니라 이 프로젝트의 결정기록 + 메이저 베이스라인으로 다룰 수 있는 여지를 남긴다

## 결과

- 스택 변경 시에도 이름·명세·프로세스가 연속성을 가진다
- 로컬 폴더명 변경(앵귤러&스프링부트 개발키트 → 웹앱 개발키트)은 세션 밖에서 수동 수행 필요

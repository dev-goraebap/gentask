# 요구사항 — 알림

상태 정의: `제안` → `확정` → `구현됨` / `폐기`

| ID | 요구사항 | 상태 |
|---|---|---|
| NOTI-01 | VAPID 기반 웹 푸시 알림을 구독·수신할 수 있다 | 제안 |
| NOTI-02 | 사용자가 알림 종류별 수신 여부를 설정할 수 있다 | 제안 |

## NOTI-01 웹 푸시

인수조건 (확정 단계에서 상세화):
- [ ] 브라우저에서 푸시 구독을 등록·해제할 수 있다
- [ ] 서버에서 특정 사용자에게 푸시를 발송할 수 있다
- [ ] 만료·무효 구독이 정리된다

## NOTI-02 알림 설정

인수조건 (확정 단계에서 상세화):
- [ ] 알림 종류별 on/off 설정이 저장된다
- [ ] 설정이 꺼진 종류의 알림은 발송되지 않는다

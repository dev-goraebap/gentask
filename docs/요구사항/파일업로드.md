# 요구사항 — 파일 업로드

상태 정의: `제안` → `확정` → `구현됨` / `폐기`

| ID | 요구사항 | 상태 |
|---|---|---|
| FILE-01 | 클라이언트가 presigned URL로 R2에 직접 업로드할 수 있다 | 제안 |
| FILE-02 | 파일 메타데이터는 Active Storage 방식(blob/attachment 분리) 테이블 구조로 관리된다 | 제안 |
| FILE-03 | 이미지 업로드 시 변환(리사이즈 등)을 수행할 수 있다 | 제안 |
| FILE-04 | 이미지 업로드 시 지배적 색상을 추출해 저장한다 | 제안 |

## FILE-01 presigned URL 업로드

인수조건 (확정 단계에서 상세화):
- [ ] 서버가 업로드용 presigned URL을 발급한다
- [ ] 클라이언트가 R2에 직접 업로드하고, 서버에 완료를 통지한다
- [ ] 허용 파일 형식·크기 제한이 적용된다

외부 의존성: Cloudflare R2.

## FILE-02 Active Storage식 테이블 구조

인수조건 (확정 단계에서 상세화):
- [ ] blob(파일 실체 메타)과 attachment(도메인 연결)가 분리된 스키마가 `docs/설계/데이터베이스.md`와 일치한다
- [ ] 하나의 blob을 여러 도메인 객체에 연결할 수 있다

## FILE-03 · FILE-04 이미지 처리

인수조건 (확정 단계에서 상세화):
- [ ] 이미지 업로드 시 정의된 변형(variant)이 생성된다
- [ ] 지배적 색상이 추출되어 blob 메타데이터에 저장된다 (플레이스홀더 배경 등에 활용)

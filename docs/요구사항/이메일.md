# 요구사항 — 이메일 발송

상태 정의: `제안` → `확정` → `구현됨` / `폐기`

| ID | 요구사항 | 상태 |
|---|---|---|
| MAIL-01 | 서버에서 트랜잭션 이메일(인증·알림 등)을 발송할 수 있다 | 제안 |

## MAIL-01 이메일 발송

인수조건 (확정 단계에서 상세화):
- [ ] 템플릿 기반으로 이메일을 발송할 수 있다
- [ ] 발송 실패 시 결과가 기록된다
- [ ] 인증 메일(AUTH-01의 이메일 검증)에 사용된다

미결정: 발송 인프라(SMTP / 외부 서비스) — 확정 시 결정기록으로 남긴다.

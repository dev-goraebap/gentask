# 2. 제약 조건 (Architecture Constraints)

시스템이 운영되는 외부 환경 및 기술적 제약 조건이다. 아키텍처 설계는 아래 제약 조건을 전제로 수행한다.

- **서버 인프라**: 단일 서버 환경에서 API를 도커(Docker) 컨테이너로 구동하고, 프론트엔드는 빌드 산출물을 nginx가 정적으로 제공한다. nginx는 정적 자산 제공과 API 리버스 프록시를 겸한다. 수평 확장(Scale-out)과 무중단 배포는 전제하지 않는다.
- **데이터베이스**: 호스트에 실행 중인 공용 PostgreSQL 인스턴스를 데이터베이스 단위로 분할하여 사용한다. 인스턴스 수준의 설정 및 관리는 본 시스템의 범위에 포함되지 않는다.
- **파일 스토리지**: 배포 환경은 Cloudflare R2, 개발 환경은 로컬 컨테이너의 MinIO를 사용하며 S3 호환 API로만 접근한다. 특정 스토리지 공급자 전용 기능은 사용하지 않는다.
- **브라우저 환경**: 별도의 브라우저 지원 목록을 정의하지 않고 Angular 프레임워크의 기본 지원 대상(Chrome, Edge, Firefox, Safari, iOS Safari 및 주요 Android 브라우저 최신 버전)을 따른다.

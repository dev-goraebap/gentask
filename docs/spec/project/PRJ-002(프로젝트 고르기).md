# PRJ-002 프로젝트 고르기

- **목표:** 다룰 프로젝트를 정해, 트래커의 모든 자리가 그 하나만 낸다.
- **주 액터:** 사용자
- **지원 액터:** 없음
- **트리거:** 지금 보는 것과 다른 프로젝트를 다뤄야 한다.

## 기본 흐름 (Basic Flow)

1. 사용자가 프로젝트 목록을 연다.
2. 시스템이 사용자의 프로젝트를 각각의 작업 아이템 수와 함께 낸다.
3. 사용자가 하나를 고른다.
4. 시스템이 그 프로젝트의 작업 아이템 자리로 옮긴다.

## 대체 흐름 (Alternate Flows)

### A1 주소로 곧바로 든다

- **시작 조건:** 사용자가 어떤 프로젝트 안의 자리를 주소로 곧바로 연다.
- **처리 절차:**
  1. 시스템이 주소가 가리킨 프로젝트를 지금 프로젝트로 삼는다.
  2. **기본 흐름 4로 복귀.**

고른 것의 진실을 주소가 갖는다. 따로 들고 있으면 새로고침과 뒤로가기에서 둘이 어긋난다.

### A2 남의 프로젝트를 연다

- **시작 조건:** A1 에서 주소가 가리킨 프로젝트가 사용자의 것이 아니다.
- **처리 절차:**
  1. 시스템이 그 자리가 없음을 알린다.
  2. **실패로 종료.** 지금 프로젝트는 바뀌지 않는다.

있으나 권한이 없다고 알리지 않는다. 그렇게 알리면 어떤 프로젝트가 존재하는지가 새어 나간다.

### A3 프로젝트가 하나뿐이다

- **시작 조건:** 2단계에서 사용자의 프로젝트가 하나다.
- **처리 절차:**
  1. 시스템이 그것을 그대로 낸다.
  2. **기본 흐름 3으로 복귀.**

고를 것이 하나여도 목록을 건너뛰지 않는다. 그 자리가 세우는 길을 함께 갖기 때문이다(PRJ-001).

### A4 공유받은 프로젝트를 고른다

- **시작 조건:** 2단계에서 사용자가 남이 공유한 프로젝트도 함께 보겠다고 한다.
- 처리 절차는 착수할 때 쓴다. 공유의 규격이 먼저 정해져야 하며 PRD 2.3 이 향후 검토로 두었다.

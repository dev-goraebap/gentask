# PRJ-002 프로젝트 선택

- **목표:** 작업 대상 프로젝트를 선택하여 트래커 화면의 작업 컨텍스트를 전환한다.
- **주 액터:** 사용자
- **지원 액터:** 없음
- **트리거:** 현재 작업 중인 프로젝트와 다른 프로젝트를 조회하거나 관리해야 한다.

## 기본 흐름 (Basic Flow)

1. 사용자가 프로젝트 목록 화면으로 진입한다.
2. 시스템이 사용자의 소유 프로젝트 목록과 각 프로젝트의 작업 아이템 수를 표시한다.
3. 사용자가 프로젝트를 선택한다.
4. 시스템이 선택된 프로젝트의 작업 아이템 목록 화면으로 이동한다.

## 대체 흐름 (Alternate Flows)

### A1 URL 직접 접근으로 프로젝트를 전환한다

- **시작 조건:** 사용자가 특정 프로젝트 경로가 포함된 URL로 직접 접근한다.
- **처리 절차:**
  1. 시스템이 URL에 명시된 프로젝트 식별자를 활성 프로젝트 컨텍스트로 설정한다.
  2. **기본 흐름 4로 복귀.**

활성 프로젝트의 단일 원본은 URL 경로다.

### A2 타인의 프로젝트에 접근한다

- **시작 조건:** A1에서 지정된 프로젝트 식별자가 사용자의 소유가 아니다.
- **처리 절차:**
  1. 시스템이 해당 리소스가 존재하지 않음을 알린다.
  2. **실패로 종료.** 기존 활성 프로젝트를 유지한다.

보안을 위해 권한 없음 대신 리소스 부재로 응답한다.

### A3 보유 프로젝트가 1개뿐이다

- **시작 조건:** 2단계에서 사용자의 소유 프로젝트가 1개뿐이다.
- **처리 절차:**
  1. 시스템이 해당 프로젝트 목록과 신규 생성 버튼을 함께 표시한다.
  2. **기본 흐름 3으로 복귀.**

### A4 공유 프로젝트 선택

- **시작 조건:** 2단계에서 타 사용자가 공유한 프로젝트를 함께 조회하려 한다.
- 처리 절차는 해당 슬라이스 착수 시 기술한다([PRD 2.3](../../prd.md)).

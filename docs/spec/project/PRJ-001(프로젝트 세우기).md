# PRJ-001 프로젝트 세우기

- **목표:** 다룰 일을 담을 자리를 만들어, 서로 다른 일이 한 목록에 섞이지 않는다.
- **주 액터:** 사용자
- **지원 액터:** 없음
- **트리거:** 지금 프로젝트에 담기지 않는 일이 생겼다.

## 기본 흐름 (Basic Flow)

1. 사용자가 프로젝트를 세우겠다고 한다.
2. 시스템이 적을 수 있게 한다.
3. 사용자가 이름을 적는다.
4. 시스템이 이름이 비어 있지 않음을 검증한다.
5. 시스템이 이름에서 접두어를 뽑는다.
6. 시스템이 프로젝트를 세우고 그 자리로 옮긴다.

접두어는 작업 아이템의 번호 앞에 붙는 것이며, 번호가 매겨진 뒤에는 바꾸지 않는다. 그래서 세울 때 한 번만 정한다.

**접두어는 영문과 숫자만 담는다.** 이 값이 주소에 그대로 들어가는데(`/projects/TG/issues`) 그 밖의 글자는 퍼센트로 인코딩되어, 링크를 복사해 건네는 순간 사람이 읽을 수 없게 된다. 주소에 접두어를 담기로 한 근거가 읽고 건넬 수 있다는 것이므로 담는 글자를 그 근거에 맞춘다.

## 대체 흐름 (Alternate Flows)

### A1 이름이 비어 있다

- **시작 조건:** 4단계에서 이름이 비어 있다.
- **처리 절차:**
  1. 시스템이 이름이 필요함을 알린다.
  2. 사용자가 이름을 다시 적는다.
  3. **기본 흐름 4로 복귀.**

### A2 접두어가 이미 쓰이고 있다

- **시작 조건:** 5단계에서 뽑은 접두어를 사용자의 다른 프로젝트가 이미 갖는다.
- **처리 절차:**
  1. 시스템이 겹치지 않는 접두어가 나올 때까지 뒤에 숫자를 붙인다.
  2. **기본 흐름 6으로 복귀.**

되묻지 않는 것은 접두어가 사용자가 고른 것이 아니라 이름에서 뽑은 것이기 때문이다. 고르게 하려면 그 자리를 먼저 화면에 두어야 한다.

접두어는 사용자 안에서만 유일하다. 다른 사용자가 같은 접두어를 갖는 것은 겹침이 아니다.

### A3 계정을 만들 때 함께 선다

- **시작 조건:** 사용자가 계정을 만든다.
- **처리 절차:**
  1. 시스템이 기본 프로젝트를 하나 세운다.
  2. **성공으로 종료.**

이 경로에는 주 액터의 개시가 없다. 프로젝트가 하나도 없는 계정은 트래커의 어느 자리에도 들어가지 못하므로, 처음 여는 사람이 빈 화면을 먼저 지나지 않게 한다. PRD 2.1 이 정한 것이다.

### A4 세우기를 그만둔다

- **시작 조건:** 1–4단계 어디서든, 사용자가 세우기를 그만둔다.
- **처리 절차:**
  1. 시스템이 프로젝트를 세우지 않는다.
  2. **실패로 종료.**

### A5 이름에서 뽑을 것이 없다

- **시작 조건:** 5단계에서 이름에 영문과 숫자가 하나도 없다.
- **처리 절차:**
  1. 시스템이 `P` 를 접두어로 삼는다.
  2. **기본 흐름 6으로 복귀.** 겹치면 A2 로 간다.

한글로만 지은 이름이 여기에 해당한다. 접두어가 이름과 이어지지 않는 것이 이 선택의 대가이며, 주소가 읽히는 것을 그보다 앞에 두었다. 사람이 접두어를 직접 고르는 자리를 두면 이 대체 흐름이 사라진다.

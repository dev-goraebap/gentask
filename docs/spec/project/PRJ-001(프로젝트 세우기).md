# PRJ-001 프로젝트 세우기

- **목표:** 다룰 일을 담을 자리를 만들어, 서로 다른 일이 한 목록에 섞이지 않는다.
- **주 액터:** 사용자
- **지원 액터:** 없음
- **트리거:** 지금 프로젝트에 담기지 않는 일이 생겼다.

## 기본 흐름 (Basic Flow)

1. 사용자가 프로젝트를 세우겠다고 한다.
2. 시스템이 적을 수 있게 한다.
3. 사용자가 이름과 작업 아이템 접두어를 적는다.
4. 시스템이 이름이 비어 있지 않고 접두어의 모양이 맞음을 검증한다.
5. 시스템이 프로젝트를 세우고 그 자리로 옮긴다.

**프로젝트를 가리키는 이름이 셋이다.** 하나가 셋을 겸하면 요구가 서로 다르므로 한쪽이 진다.

| | 무엇 | 누가 정하나 | 어디 쓰나 |
| :--- | :--- | :--- | :--- |
| 이름 | 내 프로젝트 | 사용자 | 화면에 보이는 것 |
| 식별자 | `V1StGXR8_Z5j` | 시스템 | 주소 · API 경로 · 명령줄 인자 |
| 접두어 | `GT` | 사용자 | 작업 아이템의 이름 `GT-43` |

**식별자는 시스템이 만들며 전역으로 유일하다.** 주소에 소유자가 드러나지 않으므로, 소유자 안에서만 유일하면 그 주소를 건넸을 때 받는 사람의 다른 프로젝트가 열린다.

**접두어는 사용자가 정하며 겹쳐도 막지 않는다.** 해석은 식별자가 하므로 접두어가 같아도 시스템이 헷갈릴 자리가 없다. 접두어가 영문과 숫자만 담는 것은 그것이 작업 아이템의 이름으로 커밋 메시지와 테스트 이름에 박히기 때문이며, 거기서 낱말과 섞이지 않으려면 모양이 좁아야 한다.

## 대체 흐름 (Alternate Flows)

### A1 이름이 비어 있다

- **시작 조건:** 4단계에서 이름이 비어 있다.
- **처리 절차:**
  1. 시스템이 이름이 필요함을 알린다.
  2. 사용자가 이름을 다시 적는다.
  3. **기본 흐름 4로 복귀.**

### A2 접두어의 모양이 맞지 않는다

- **시작 조건:** 4단계에서 접두어가 비어 있거나 영문과 숫자가 아닌 것을 담는다.
- **처리 절차:**
  1. 시스템이 무엇이 허용되는지 알린다.
  2. 사용자가 접두어를 다시 적는다.
  3. **기본 흐름 4로 복귀.**

접두어가 겹치는 것은 이 흐름에 들지 않는다. 겹침을 막지 않으므로 검증할 것이 없다.

### A3 계정을 만들 때 함께 선다

- **시작 조건:** 사용자가 계정을 만든다.
- **처리 절차:**
  1. 시스템이 기본 프로젝트를 하나 세운다.
  2. **성공으로 종료.**

이 경로에는 주 액터의 개시가 없다. 프로젝트가 하나도 없는 계정은 트래커의 어느 자리에도 들어가지 못하므로, 처음 여는 사람이 빈 화면을 먼저 지나지 않게 한다. PRD 2.1 이 정한 것이다.

접두어를 고를 자리도 없으므로 시스템이 기본값을 쓴다. 이름에서 뽑지 않는 것은, 한글로만 지은 이름에서 남는 것이 없어 뜻 없는 값이 커밋의 `Refs:` 에 박히기 때문이다.

### A4 세우기를 그만둔다

- **시작 조건:** 1–4단계 어디서든, 사용자가 세우기를 그만둔다.
- **처리 절차:**
  1. 시스템이 프로젝트를 세우지 않는다.
  2. **실패로 종료.**

### A5 (결번)

접두어를 이름에서 뽑던 때의 흐름이다. 뽑을 것이 없으면 `P` 를 쓰던 자리이며, 접두어를 사용자가 정하게 되면서 사라졌다. 번호는 부여 뒤 바꾸지 않으므로 결번으로 남긴다.

# USR-002 계정 로그인

- **목표:** 등록된 계정으로 인증하여 자신의 작업 및 프로젝트 데이터에 접근한다.
- **주 액터:** 사용자
- **지원 액터:** 없음
- **트리거:** 인증 세션이 만료되었거나 비로그인 상태에서 서비스에 진입했다.

## 기본 흐름 (Basic Flow)

1. 사용자가 이메일과 비밀번호를 입력한다.
2. 시스템이 사용자 자격 증명을 검증한다.
3. 시스템이 인증 세션을 발급하고 로그인 상태를 수립한다.
4. 사용자가 기본 프로젝트의 작업 목록 화면으로 이동한다.

계정이 없는 경우 [USR-001 계정 회원가입](<./USR-001(계정 회원가입).md>)으로 이동한다.

## 대체 흐름 (Alternate Flows)

### A1 자격 증명이 일치하지 않는다

- **시작 조건:** 2단계에서 이메일 또는 비밀번호 검증에 실패한다.
- **처리 절차:**
  1. 시스템이 이메일 또는 비밀번호가 올바르지 않음을 안내한다.
  2. **기본 흐름 1로 복귀.**

이메일 존재 여부 유출을 방지하기 위해 계정 미존재 시에도 동일한 오류 메시지를 반환한다.

### A2 비인가 상태에서 보호된 리소스에 접근한다

- **시작 조건:** 비로그인 상태에서 작업 화면 등 보호된 엔드포인트에 직접 접근한다.
- **처리 절차:**
  1. 시스템이 리소스 조회를 차단하고 로그인 화면으로 리다이렉트한다.
  2. **기본 흐름 1로 복귀.**

비밀번호 분실 시에는 [USR-005 비밀번호 재설정](<./USR-005(비밀번호 재설정).md>)으로 이동한다.

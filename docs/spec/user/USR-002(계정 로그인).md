# USR-002 계정 로그인

- **목표:** 내 계정으로 돌아와, 어느 자리에서든 내 목록을 본다.
- **주 액터:** 사용자
- **지원 액터:** 없음
- **트리거:** 로그인이 풀린 채 돌아왔다.

## 기본 흐름 (Basic Flow)

1. 사용자가 이메일과 비밀번호를 제공한다.
2. 시스템이 자격을 검증한다.
3. 시스템이 로그인 상태를 만들고 유지한다.
4. 사용자가 자신의 작업 목록을 본다.

계정이 없으면 [USR-001 계정 회원가입](<./USR-001(계정 회원가입).md>)으로 간다. 가입은 끝나는 즉시 로그인 상태이므로 이 흐름을 다시 거치지 않는다.

## 대체 흐름 (Alternate Flows)

### A1 자격이 맞지 않는다

- **시작 조건:** 2단계에서 자격이 검증되지 않는다.
- **처리 절차:**
  1. 시스템이 이메일과 비밀번호가 맞지 않음을 알린다. 어느 쪽이 틀렸는지는 구분하지 않는다.
  2. **기본 흐름 1로 복귀.**

계정이 없는 경우도 이 흐름을 탄다. 구분해 알리면 그 차이가 곧 그 이메일로 가입된 계정이 있다는 정보가 된다.

### A2 로그인 없이 접근한다

- **시작 조건:** 로그인 상태가 아닌 채 작업 화면에 접근한다.
- **처리 절차:**
  1. 시스템이 작업을 보여 주지 않고 로그인 자리로 안내한다.
  2. **기본 흐름 1로 복귀.**

비밀번호가 기억나지 않으면 [USR-005 비밀번호 재설정](<./USR-005(비밀번호 재설정).md>)으로 간다.

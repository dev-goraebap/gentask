# USR-004 계정 로그아웃

- **목표:** 내 자리를 정리하고 떠나, 이 기기에 내 목록이 남지 않게 한다.
- **주 액터:** 사용자
- **지원 액터:** 없음
- **트리거:** 공용 기기에서 썼거나, 다른 계정으로 바꾸려 한다.

## 기본 흐름 (Basic Flow)

1. 사용자가 로그아웃한다.
2. 시스템이 로그인 상태를 거둔다.

이후 접근은 [USR-002 계정 로그인](<./USR-002(계정 로그인).md>)의 A2 를 따른다.

## 미결

- 기기(세션) 목록과 개별 로그아웃. 여러 기기에서 쓰기 시작하면 올린다
- 다른 기기 전체 로그아웃. 비밀번호를 바꿀 때 함께 정한다

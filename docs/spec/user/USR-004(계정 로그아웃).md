# USR-004 계정 로그아웃

- **목표:** 현재 기기의 인증 세션을 만료시켜 계정 접근을 차단한다.
- **주 액터:** 사용자
- **지원 액터:** 없음
- **트리거:** 공용 기기 사용을 종료하거나 다른 계정으로 전환해야 한다.

## 기본 흐름 (Basic Flow)

1. 사용자가 로그아웃을 요청한다.
2. 시스템이 현재 세션을 만료 처리하고 쿠키를 파기한다.

로그아웃 후 보호된 리소스에 접근하는 경우 [USR-002 계정 로그인](<./USR-002(계정 로그인).md>)의 A2를 따른다.

## 미결

- 활성 세션 목록 조회 및 원격 세션 개별 로그아웃 기능
- 타 기기 전체 일괄 로그아웃 기능

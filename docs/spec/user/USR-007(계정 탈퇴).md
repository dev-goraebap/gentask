# USR-007 계정 탈퇴

- **목표:** 이 서비스를 더 쓰지 않기로 하고, 남긴 것을 지운다.
- **주 액터:** 사용자
- **지원 액터:** 없음
- **트리거:** 더 쓰지 않기로 했다.

> 초안이다. 기본 흐름은 단계까지 쓰고 대체 흐름은 조건 이름만 둔다. 세부 절차는 그 흐름을 지나는 슬라이스에 착수할 때 쓴다.

## 기본 흐름 (Basic Flow)

1. 사용자가 프로필에서 탈퇴한다고 한다.
2. 시스템이 무엇이 지워지는지와 되돌릴 수 없음을 알린다.
3. 사용자가 확인한다.
4. 시스템이 계정과 그 계정의 작업과 붙인 파일을 지운다.
5. 시스템이 로그인 상태를 거두고 첫 화면으로 보낸다.

1단계의 자리는 [USR-003 프로필 관리](<./USR-003(프로필 관리).md>)의 화면이다.

## 대체 흐름 (Alternate Flows)

- **A1 확인하지 않는다**

## 미결

- **보관소의 객체는 외래 키가 닿지 않는다.** 데이터베이스는 계정을 지우면 자격 · 세션 · API 토큰 · 작업 · 붙인 파일의 행이 함께 지워지지만, 프로필 이미지와 붙인 파일의 실체는 오브젝트 스토리지에 있어 따로 지워야 한다. 지우다 실패했을 때 어디까지 되돌리는지도 여기서 정한다
- 재확인 수단. 로그인 상태만으로 충분한지, 비밀번호를 다시 받을지
- 유예 기간. 지금은 즉시 삭제를 전제하며 되돌리기를 두지 않는다
- 같은 이메일로 다시 가입할 수 있는지. 막으려면 지운 뒤에도 남기는 것이 생긴다

# USR-007 계정 탈퇴

- **목표:** 계정을 삭제하고 관련 개인 데이터 및 작업 데이터를 영구 제거한다.
- **주 액터:** 사용자
- **지원 액터:** 없음
- **트리거:** 서비스 탈퇴를 결정했다.

## 기본 흐름 (Basic Flow)

1. 사용자가 프로필 관리 화면에서 회원 탈퇴를 요청한다.
2. 시스템이 삭제 대상 데이터 범위와 작업의 불가역성을 안내한다.
3. 사용자가 탈퇴를 확정한다.
4. 시스템이 계정 및 소유한 작업, 문서, 첨부 파일 데이터를 삭제 처리한다.
5. 시스템이 인증 세션을 만료 처리하고 메인 화면으로 이동한다.

## 대체 흐름 (Alternate Flows)

- **A1 탈퇴를 취소한다**

## 미결

- 오브젝트 스토리지 내 첨부 파일 및 프로필 이미지 비동기 삭제 처리 정책
- 탈퇴 확정 시 비밀번호 재입력 등 추가 인증 절차 도입 여부
- 탈퇴 유예 기간(Grace Period) 도입 여부
- 탈퇴한 이메일 주소의 재가입 허용 정책

# USR-006 비밀번호 변경

- **목표:** 기존 비밀번호를 변경하여 계정 보안을 강화한다.
- **주 액터:** 사용자
- **지원 액터:** 없음
- **트리거:** 비밀번호 변경 주기 도래 또는 계정 보안 강화가 필요하다.

## 기본 흐름 (Basic Flow)

1. 사용자가 프로필 관리 화면에서 비밀번호 변경을 요청한다.
2. 사용자가 현재 비밀번호와 새 비밀번호를 입력한다.
3. 시스템이 현재 비밀번호의 일치 여부와 새 비밀번호의 복잡도 규칙 충족 및 기존 비밀번호와의 상이성을 검증한다.
4. 시스템이 비밀번호를 갱신하고 현재 세션을 제외한 타 기기의 모든 세션을 만료 처리한다.
5. 사용자가 변경 완료를 확인한다.

계정 탈취 방지를 위해 현재 비밀번호를 재입력받아 본인을 재검증한다.

현재 요청 세션은 유지하여 사용자 편의성을 보장하되, 타 세션은 일괄 만료하여 보안을 확보한다. API 토큰은 유지한다.

## 대체 흐름 (Alternate Flows)

### A1 현재 비밀번호가 일치하지 않는다

- **시작 조건:** 3단계에서 입력된 현재 비밀번호가 일치하지 않는다.
- **처리 절차:**
  1. 시스템이 현재 비밀번호가 올바르지 않음을 안내한다.
  2. **기본 흐름 2로 복귀.**

비밀번호 분실 시에는 [USR-005 비밀번호 재설정](<./USR-005(비밀번호 재설정).md>)으로 이동한다.

### A2 새 비밀번호가 규칙에 부합하지 않는다

- **시작 조건:** 3단계에서 새 비밀번호가 복잡도 규칙을 충족하지 못한다.
- **처리 절차:**
  1. 시스템이 미충족 규칙을 안내한다.
  2. **기본 흐름 2로 복귀.**

비밀번호 규칙은 [결정-0012](../../architecture/decisions/0012-shared-credential-policy.md)를 따른다.

### A3 새 비밀번호가 현재 비밀번호와 동일하다

- **시작 조건:** 3단계에서 새 비밀번호가 현재 비밀번호와 동일하다.
- **처리 절차:**
  1. 시스템이 기존과 다른 새 비밀번호를 입력해야 함을 안내한다.
  2. **기본 흐름 2로 복귀.**

## 미결

- 비밀번호 변경 완료 안내 이메일 발송 여부

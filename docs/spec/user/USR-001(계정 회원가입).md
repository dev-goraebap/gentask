# USR-001 계정 회원가입

- **목표:** 내 것을 담아 둘 자리를 만들어, 이 시스템을 쓰기 시작한다.
- **주 액터:** 사용자
- **지원 액터:** 없음
- **트리거:** 시스템을 처음 쓰려 한다.

## 기본 흐름 (Basic Flow)

1. 사용자가 이메일과 비밀번호를 제공한다.
2. 시스템이 이메일 형식과 그 이메일이 쓰이지 않았음을 검증한다.
3. 시스템이 계정을 만들고 곧바로 로그인 상태를 만든다.
4. 사용자가 자신의 작업 목록을 본다.

가입이 끝나면 로그인 상태다. 가입한 뒤 다시 로그인하게 만들지 않는다.

## 대체 흐름 (Alternate Flows)

### A1 이미 등록된 이메일이다

- **시작 조건:** 2단계에서 그 이메일이 이미 쓰이고 있다.
- **처리 절차:**
  1. 시스템이 이미 등록된 이메일임을 알린다.
  2. **실패로 종료.** 그 계정으로 들어가는 길은 [USR-002 계정 로그인](<./USR-002(계정 로그인).md>)이다.

### A2 이메일 형식이 아니다

- **시작 조건:** 2단계에서 이메일 형식이 아니다.
- **처리 절차:**
  1. 시스템이 형식이 맞지 않음을 알린다.
  2. **기본 흐름 1로 복귀.**

## 미결

- 이메일 소유 확인(메일 인증). 넣게 되면 기본 흐름 2단계와 3단계 사이에 들어온다
- 비밀번호 정책(길이 · 구성). 지금은 형식만 본다

# USR-003 프로필 관리

- **목표:** 사용자 계정 프로필 정보를 갱신하고 에이전트 연동용 API 토큰을 관리한다.
- **주 액터:** 사용자
- **지원 액터:** 없음
- **트리거:** 프로필 정보 수정 또는 CLI 에이전트 연동 토큰 발급이 필요하다.

## 기본 흐름 (Basic Flow)

1. 사용자가 프로필 관리 화면으로 진입한다.
2. 시스템이 아바타 이미지와 기본 계정 정보(이메일, 닉네임, 가입 일자)를 표시한다.
3. 사용자가 닉네임을 수정한다.
4. 시스템이 프로필 정보를 갱신한다.
5. 사용자가 갱신된 프로필 정보를 확인한다.

## 대체 흐름 (Alternate Flows)

선택적 단계(A1–A3)는 상호 조합될 수 있으며 조합마다 별도의 대체 흐름을 생성하지 않는다.

### A1 프로필 이미지를 등록한다

- **시작 조건:** 2단계 후, 사용자가 프로필 이미지 업로드를 요청한다.
- **처리 절차:**
  1. 사용자가 이미지 파일을 선택한다.
  2. 시스템이 이미지 파일 형식과 용량(1MB 이하)을 검증한다.
  3. 시스템이 이미지를 저장하고 아바타 영역에 반영한다.
  4. **기본 흐름 5로 복귀.**

### A2 프로필 이미지를 삭제한다

- **시작 조건:** 2단계 후, 사용자가 기존 프로필 이미지 삭제를 요청한다.
- **처리 절차:**
  1. 시스템이 저장된 이미지를 삭제하고 기본 아바타로 복원한다.
  2. **기본 흐름 5로 복귀.**

### A3 에이전트 API 토큰을 발급한다

- **시작 조건:** 2단계 후, 사용자가 CLI 에이전트 연동용 API 토큰 발급을 요청한다.
- **처리 절차:**
  1. 시스템이 신규 API 토큰을 발급하여 화면에 **최초 1회** 노출한다. 이후에는 발급 이력 메타데이터만 표시한다.
  2. 사용자가 발급된 토큰을 복사하여 로컬 에이전트 환경에 설정한다.
  3. **기본 흐름 5로 복귀.**

재발급 시 기존 발급 토큰은 즉시 무효화 처리된다.

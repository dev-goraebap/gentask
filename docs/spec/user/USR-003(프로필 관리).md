# USR-003 프로필 관리

- **목표:** 계정이 나를 알아보게 하고, 내 도구(에이전트)가 내 계정으로 일할 준비를 갖춘다.
- **주 액터:** 사용자
- **지원 액터:** 없음
- **트리거:** 내 정보가 비어 있거나 틀렸다. 또는 에이전트에 내 계정을 연결하려 한다.

## 기본 흐름 (Basic Flow)

1. 사용자가 프로필을 연다.
2. 시스템이 아바타와 기본 정보(이메일 · 별명 · 가입일)를 보여 준다. 이미지가 없으면 기본 아바타를 보인다.
3. 사용자가 별명을 고친다.
4. 시스템이 프로필을 갱신한다.
5. 사용자가 바뀐 프로필을 확인한다.

## 대체 흐름 (Alternate Flows)

선택(A1–A3)은 서로 조합될 수 있다. 조합마다 대체 흐름을 두지 않는다.

### A1 프로필 이미지를 올린다

- **시작 조건:** 2단계 뒤, 사용자가 이미지를 올리겠다고 한다.
- **처리 절차:**
  1. 사용자가 이미지 파일을 고른다.
  2. 시스템이 이미지 형식과 크기(1MB 이하)를 검증한다.
  3. 시스템이 이미지를 보관하고 아바타 자리에 보인다.
  4. **기본 흐름 5로 복귀.**

### A2 프로필 이미지를 지운다

- **시작 조건:** 2단계 뒤, 이미지가 있는 상태에서 사용자가 지우겠다고 한다.
- **처리 절차:**
  1. 시스템이 이미지를 지우고 기본 아바타로 되돌린다.
  2. **기본 흐름 5로 복귀.**

### A3 에이전트 토큰을 발급한다

- **시작 조건:** 2단계 뒤, 사용자가 에이전트에 계정을 연결할 토큰을 원한다.
- **처리 절차:**
  1. 시스템이 토큰을 만들어 **한 번만** 보여 준다. 이후에는 발급 사실만 남는다.
  2. 사용자가 토큰을 복사해 에이전트 설정에 둔다.
  3. **기본 흐름 5로 복귀.**
- 다시 발급하면 이전 토큰은 무효가 된다. 토큰을 지우면 에이전트의 접근도 끊긴다.

### A4 (결번)

식별 가능한 사유가 아니어서 걷었다.

## 미결

- 에이전트가 토큰으로 작업을 등록하는 흐름: 후보 액터(로컬 에이전트)가 올라올 때 별도 유스케이스로 연다. 이 유스케이스는 토큰을 준비하는 데까지다
- 토큰 여러 개와 이름 붙이기: 에이전트가 둘 이상 되면 올린다

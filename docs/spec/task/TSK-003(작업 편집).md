# TSK-003 작업 편집

- **목표:** 변경된 정보를 작업에 반영하여 최신 작업 내용을 유지한다.
- **주 액터:** 사용자
- **지원 액터:** 없음
- **트리거:** 제목, 메모, 기한, 미리 알림, 플래그 등 작업 속성의 변경이 필요하다.

## 기본 흐름 (Basic Flow)

1. 사용자가 편집할 작업을 선택한다.
2. 시스템이 해당 작업의 상세 정보를 표시한다.
3. 사용자가 제목을 수정한다.
4. 시스템이 제목이 비어 있지 않음을 검증한다.
5. 시스템이 변경 사항을 저장한다.
6. 사용자가 갱신된 작업 내용을 확인한다.

## 대체 흐름 (Alternate Flows)

기본 흐름 3–5는 제목 편집 경로다. 타 속성은 A2–A5 및 A10을 통해 편집 즉시 개별 갱신된다. 각 선택 단계는 상호 조합될 수 있다.

### A1 제목이 비어 있다

- **시작 조건:** 4단계에서 제목이 비어 있다.
- **처리 절차:**
  1. 시스템이 제목 입력이 필요함을 알린다.
  2. 사용자가 제목을 다시 입력한다.
  3. **기본 흐름 4로 복귀.**
- 사용자가 취소하면 A7로 이동한다.

### A2 메모를 편집한다

- **시작 조건:** 2단계 후, 사용자가 메모 수정을 요청한다.
- **처리 절차:**
  1. 사용자가 메모 내용을 수정한다.
  2. 시스템이 메모를 갱신한다.
  3. **기본 흐름 6으로 복귀.**

### A3 기한을 편집한다

- **시작 조건:** 2단계 후, 사용자가 기한 수정을 요청한다.
- **처리 절차:**
  1. 사용자가 기한을 설정하거나 해제한다.
  2. 시스템이 기한을 갱신한다.
  3. **기본 흐름 6으로 복귀.**

### A4 중요 표시를 변경한다

- **시작 조건:** 2단계 후, 사용자가 중요 플래그 변경을 요청한다.
- **처리 절차:**
  1. 사용자가 중요 플래그를 설정하거나 해제한다.
  2. 시스템이 플래그 상태를 갱신한다.
  3. **기본 흐름 6으로 복귀.**

### A5 나의 하루 설정을 변경한다

- **시작 조건:** 2단계 후, 사용자가 '나의 하루' 포함 여부 변경을 요청한다.
- **처리 절차:**
  1. 사용자가 '나의 하루'에 추가하거나 제외한다.
  2. 시스템이 상태를 갱신한다.
  3. **기본 흐름 6으로 복귀.**

### A6 (결번)

작업 삭제는 [TSK-005](<./TSK-005(작업 삭제).md>)로 분리되었다.

### A7 편집을 취소한다

- **시작 조건:** 1–4단계에서 사용자가 편집을 취소한다.
- **처리 절차:**
  1. 시스템이 제목 변경 사항을 반영하지 않는다.
  2. **실패로 종료.** 직전까지 개별 반영된 타 속성(A2–A5, A10)은 유지된다.

### A8 대상 작업이 존재하지 않는다

- **시작 조건:** 1단계에서 선택하려는 작업이 존재하지 않는다.
- **처리 절차:**
  1. 시스템이 해당 리소스가 존재하지 않음을 알린다.
  2. **실패로 종료.**

### A9 (결번)

### A10 미리 알림을 편집한다

- **시작 조건:** 2단계 후, 사용자가 미리 알림 수정을 요청한다.
- **처리 절차:**
  1. 사용자가 알림 시각을 설정하거나 해제한다.
  2. 시스템이 미리 알림 시각을 갱신한다.
  3. **기본 흐름 6으로 복귀.**

기한(A3)과 미리 알림(A10)은 독립 속성이다.

### A11 파일을 첨부하거나 삭제한다

- **시작 조건:** 2단계 후, 사용자가 파일 첨부 또는 첨부 관리를 요청한다.
- **처리 절차:**
  1. 사용자가 첨부할 파일을 선택한다.
  2. 시스템이 파일 개수(작업당 최대 5개) 및 파일 크기(건당 최대 10MB)를 검증한다.
  3. 시스템이 파일을 업로드하고 작업에 바인딩한다.
  4. **기본 흐름 6으로 복귀.**
- 검증 실패 시 시스템이 사유를 알리고 1단계로 복귀한다.
- 첨부된 파일은 다운로드하거나 삭제할 수 있으며, 삭제 시 스토리지 객체도 함께 삭제 처리한다.

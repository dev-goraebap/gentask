# TSK-003 작업 편집

- **목표:** 적힌 작업을 지금 아는 것과 같게 만든다.
- **주 액터:** 사용자
- **지원 액터:** 없음
- **트리거:** 제목·메모·기한·미리 알림·표시가 틀렸다.

## 기본 흐름 (Basic Flow)

1. 사용자가 편집할 작업을 고른다.
2. 시스템이 그 작업의 현재 내용을 보여 준다.
3. 사용자가 제목을 편집한다.
4. 시스템이 제목이 비어 있지 않음을 검증한다.
5. 시스템이 작업을 갱신한다.
6. 사용자가 바뀐 내용을 확인한다.

## 대체 흐름 (Alternate Flows)

기본 흐름 3–5는 제목을 편집하는 경우다. 다른 속성은 A2–A5와 A10이 같은 자리를 대신하며, 각 속성은 편집한 즉시 갱신된다. 선택(A2–A5, A10)은 서로 조합될 수 있다. 조합마다 대체 흐름을 두지 않는다.

### A1 제목이 비어 있다

- **시작 조건:** 4단계에서 제목이 비어 있다.
- **처리 절차:**
  1. 시스템이 제목이 필요함을 알린다.
  2. 사용자가 제목을 다시 편집한다.
  3. **기본 흐름 4로 복귀.**
- 사용자가 그만두면 A7로 간다.

### A2 메모를 편집한다

- **시작 조건:** 2단계 뒤, 사용자가 메모를 편집하겠다고 한다.
- **처리 절차:**
  1. 사용자가 메모를 편집한다.
  2. 시스템이 메모를 갱신한다.
  3. **기본 흐름 6으로 복귀.**

### A3 기한을 편집한다

- **시작 조건:** 2단계 뒤, 사용자가 기한을 편집하겠다고 한다.
- **처리 절차:**
  1. 사용자가 기한을 정하거나 뗀다.
  2. 시스템이 기한을 갱신한다.
  3. **기본 흐름 6으로 복귀.**

### A4 중요 표시를 바꾼다

- **시작 조건:** 2단계 뒤, 사용자가 중요 표시를 바꾸겠다고 한다.
- **처리 절차:**
  1. 사용자가 중요하다고 하거나 그 표시를 뗀다.
  2. 시스템이 표시를 갱신한다.
  3. **기본 흐름 6으로 복귀.**

### A5 나의 하루 추가를 바꾼다

- **시작 조건:** 2단계 뒤, 사용자가 나의 하루 추가를 바꾸겠다고 한다.
- **처리 절차:**
  1. 사용자가 나의 하루에 추가하거나 뺀다.
  2. 시스템이 담은 상태를 갱신한다.
  3. **기본 흐름 6으로 복귀.**

### A6 (결번)

삭제는 [TSK-005 작업 삭제](<./TSK-005(작업 삭제).md>)로 분리했다.

### A7 편집을 그만둔다

- **시작 조건:** 1–4단계 어디서든, 사용자가 그만둔다.
- **처리 절차:**
  1. 시스템이 편집하던 제목을 반영하지 않는다.
  2. **실패로 종료.** 제목은 편집 전과 같다. 그 전에 A2–A5와 A10으로 갱신한 값은 이미 반영되어 있다.

### A8 고르려 한 작업이 없다

- **시작 조건:** 1단계에서 고르려 한 작업이 없다.
- **처리 절차:**
  1. 시스템이 그 작업을 보여 주지 않는다.
  2. **실패로 종료.**

### A9 (결번)

식별 가능한 사유가 아니어서 걷었다.

### A10 미리 알림을 편집한다

- **시작 조건:** 2단계 뒤, 사용자가 미리 알림을 편집하겠다고 한다.
- **처리 절차:**
  1. 사용자가 알릴 시각을 정하거나 뗀다.
  2. 시스템이 미리 알림을 갱신한다.
  3. **기본 흐름 6으로 복귀.**

기한(A3)과 미리 알림은 서로를 정하지 않는다. 기한만 있는 작업과 미리 알림만 있는 작업이 모두 성립한다.

### A11 파일을 붙이거나 뗀다

- **시작 조건:** 2단계 뒤, 사용자가 파일을 붙이거나 붙인 파일을 다루겠다고 한다.
- **처리 절차:**
  1. 사용자가 붙일 파일을 고른다. 한 번에 여럿을 고를 수 있다.
  2. 시스템이 개수(작업당 최대 5개)와 크기(각 10MB 이하)를 검증한다.
  3. 시스템이 파일을 보관하고 작업에 붙인다.
  4. **기본 흐름 6으로 복귀.**
- 검증에 걸리면 시스템이 사유를 알리고 1로 복귀한다.
- 붙인 파일은 내려받거나 뗄 수 있다. 떼면 보관된 파일도 함께 지운다. 되살리는 수단은 두지 않는다.

## 미결

화면으로 정하지 못한 것이다. 해당 슬라이스에 착수할 때 정한다.

- 삭제 복구: 삭제한(A6) 작업을 되살릴 수 있어야 하는지. 없으면 확인 단계가 유일한 안전장치다

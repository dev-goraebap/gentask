# TSK-004 작업 완료

- **목표:** 완료된 작업을 처리하여 미완료 작업 목록에서 제외하고 잔여 작업을 명확히 한다.
- **주 액터:** 사용자
- **지원 액터:** 없음
- **트리거:** 대상 작업의 수행을 완료했다.

## 기본 흐름 (Basic Flow)

1. 사용자가 완료할 작업을 선택한다.
2. 사용자가 작업 완료를 요청한다.
3. 시스템이 작업 상태를 완료(DONE)로 갱신한다.
4. 시스템이 미완료 작업 목록에서 해당 항목을 제외한다.
5. 사용자가 갱신된 잔여 작업 목록을 확인한다.

## 대체 흐름 (Alternate Flows)

### A1 이미 완료된 작업이다

- **시작 조건:** 2단계에서 대상 작업이 이미 완료 상태다.
- **처리 절차:**
  1. 시스템이 상태를 변경하지 않는다.
  2. **다른 성공으로 종료.**

### A2 완료를 취소한다

- **시작 조건:** 완료 상태인 작업에 대해 사용자가 완료 취소를 요청한다.
- **처리 절차:**
  1. 사용자가 완료 취소를 요청한다.
  2. 시스템이 완료 상태를 해제하고 미완료 작업 목록에 다시 복원한다.
  3. **다른 성공으로 종료.**

### A3 대상 작업이 존재하지 않는다

- **시작 조건:** 1단계에서 선택하려는 작업이 존재하지 않는다.
- **처리 절차:**
  1. 시스템이 해당 리소스가 존재하지 않음을 알린다.
  2. **실패로 종료.**

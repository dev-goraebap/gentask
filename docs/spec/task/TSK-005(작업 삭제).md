# TSK-005 작업 삭제

- **목표:** 불필요하거나 잘못 등록된 작업을 삭제하여 목록을 정돈한다.
- **주 액터:** 사용자
- **지원 액터:** 없음
- **트리거:** 작업을 수행하지 않기로 결정했거나 잘못 등록했다.

## 기본 흐름 (Basic Flow)

1. 사용자가 삭제할 작업을 선택한다.
2. 사용자가 작업 삭제를 요청한다.
3. 시스템이 삭제 재확인을 요청한다.
4. 사용자가 삭제를 확정한다.
5. 시스템이 작업을 목록에서 삭제한다.

완료 처리([TSK-004](<./TSK-004(작업 완료).md>))와 구분한다. 완료된 작업은 이력으로 보존되나 본 흐름은 작업을 영구 제거한다.

## 대체 흐름 (Alternate Flows)

### A1 삭제를 취소한다

- **시작 조건:** 4단계에서 사용자가 확인을 취소한다.
- **처리 절차:**
  1. 시스템이 작업을 삭제하지 않는다.
  2. **다른 성공으로 종료.**

### A2 대상 작업이 존재하지 않는다

- **시작 조건:** 1단계에서 선택하려는 작업이 존재하지 않는다.
- **처리 절차:**
  1. 시스템이 해당 리소스가 존재하지 않음을 알린다.
  2. **실패로 종료.**

## 미결

해당 슬라이스 착수 시 확정한다.

- 삭제 복구(휴지통 지원 여부)
- 첨부 파일 연계 삭제: [TSK-003](<./TSK-003(작업 편집).md>) A11의 첨부 관리 정책과 연계

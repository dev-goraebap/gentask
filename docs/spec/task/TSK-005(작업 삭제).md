# TSK-005 작업 삭제

- **목표:** 필요 없어진 것을 목록에서 치워, 목록이 지금 할 일만 갖게 한다.
- **주 액터:** 사용자
- **지원 액터:** 없음
- **트리거:** 이 일은 하지 않기로 했거나, 잘못 적었다.

## 기본 흐름 (Basic Flow)

1. 사용자가 삭제할 작업을 고른다.
2. 사용자가 이 작업을 삭제한다고 한다.
3. 시스템이 되돌릴 수 없음을 확인받는다.
4. 사용자가 확인한다.
5. 시스템이 작업을 목록에서 뺀다.

완료한 작업을 치우는 것은 삭제가 아니다. 그것은 [TSK-004 작업 완료](<./TSK-004(작업 완료).md>)이며 목록에 완료된 작업으로 남는다.

## 대체 흐름 (Alternate Flows)

### A1 확인하지 않는다

- **시작 조건:** 4단계에서 사용자가 확인하지 않는다.
- **처리 절차:**
  1. 시스템이 작업을 그대로 둔다.
  2. **별도 성공 출구.** 그 작업은 목록에 남는다.

### A2 고르려 한 작업이 없다

- **시작 조건:** 1단계에서 고르려 한 작업이 없다.
- **처리 절차:**
  1. 시스템이 그 작업을 보여 주지 않는다.
  2. **실패로 종료.**

## 미결

- 되돌리기(휴지통). 지금은 되돌릴 수 없음을 확인받는 것으로 대신한다
- 붙인 파일의 처리. 작업을 지울 때 보관소의 파일도 함께 지우는지는 [TSK-003 작업 편집](<./TSK-003(작업 편집).md>) A11 과 함께 정한다

# TSK-002 작업 조회

- **목표:** 등록된 작업 목록을 조건별로 조회하여 수행할 작업을 선정한다.
- **주 액터:** 사용자
- **지원 액터:** 없음
- **트리거:** 다음에 수행할 작업을 확인하거나 업무를 선정해야 한다.

## 기본 흐름 (Basic Flow)

1. 사용자가 작업 목록 화면으로 진입한다.
2. 시스템이 미완료 상태인 작업 목록을 조회하여 표시한다.
3. 사용자가 목록을 검토한다.
4. 사용자가 수행할 작업 하나를 선택한다.

## 대체 흐름 (Alternate Flows)

스마트 목록(A2–A4)은 동일한 조회 목표를 공유하는 필터링 대체 경로다.

### A1 완료된 작업을 조회한다

- **시작 조건:** 1단계 후, 사용자가 완료된 작업 조회를 요청한다.
- **처리 절차:**
  1. 시스템이 현재 목록의 완료된 작업을 표시한다.
  2. **기본 흐름 3으로 복귀.**

### A2 나의 하루 작업만 조회한다

- **시작 조건:** 1단계 후, 사용자가 '나의 하루' 필터 조회를 요청한다.
- **처리 절차:**
  1. 시스템이 '나의 하루'에 포함된 미완료 작업만 표시한다.
  2. **기본 흐름 3으로 복귀.**

### A3 중요 작업만 조회한다

- **시작 조건:** 1단계 후, 사용자가 '중요' 필터 조회를 요청한다.
- **처리 절차:**
  1. 시스템이 중요 표시된 미완료 작업만 표시한다.
  2. **기본 흐름 3으로 복귀.**

### A4 기한이 설정된 작업만 조회한다

- **시작 조건:** 1단계 후, 사용자가 '기한' 필터 조회를 요청한다.
- **처리 절차:**
  1. 시스템이 완료 기한이 지정된 미완료 작업만 표시한다.
  2. **기본 흐름 3으로 복귀.**

### A5 조회 결과가 없다

- **시작 조건:** 2단계 또는 A1–A4 단계에서 조건에 부합하는 작업이 존재하지 않는다.
- **처리 절차:**
  1. 시스템이 작업이 존재하지 않음을 안내한다.
  2. **다른 성공으로 종료.**

### A6 정렬 기준을 변경한다

- **시작 조건:** 2단계 후, 사용자가 정렬 기준 변경을 요청한다.
- **처리 절차:**
  1. 사용자가 정렬 기준(중요도, 기한, 나의 하루, 제목, 생성일)을 선택한다.
  2. 시스템이 해당 기준에 따라 미완료 작업을 재정렬하여 표시한다. 기준값이 없는 항목은 후순위로 배치한다.
  3. 동일 기준을 재선택하면 정렬 방향을 반전한다.
  4. **기본 흐름 3으로 복귀.**

기본 정렬 기준은 생성일 내림차순(최신순)이다.

### A7 유효하지 않은 스마트 목록 식별자로 접근한다

- **시작 조건:** 1단계에서 시스템이 지원하지 않는 스마트 목록 경로로 접근한다.
- **처리 절차:**
  1. 시스템이 기본 미완료 작업 목록으로 대체하여 표시한다.
  2. **기본 흐름 3으로 복귀.**

### A8 (결번)

## 미결

- 스마트 목록 정렬 상태 유지: 뷰 전환 시 정렬 기준 지속 여부

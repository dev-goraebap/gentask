# DOC-008 폴더 관리

- **목표:** 문서를 폴더 계층으로 분류하여 탐색성과 접근성을 개선한다.
- **주 액터:** 사용자
- **지원 액터:** 없음
- **트리거:** 문서 수가 증가하여 계층 구조 기반의 분류가 필요하다.

## 기본 흐름 (Basic Flow)

1. 사용자가 문서 목록 화면으로 진입한다.
2. 사용자가 폴더 생성을 요청한다.
3. 시스템이 폴더 이름 입력 폼을 활성화한다.
4. 사용자가 폴더 이름을 입력한다.
5. 시스템이 폴더 이름이 비어 있지 않음을 검증한다.
6. 시스템이 현재 경로 아래에 폴더를 생성하고 목록에 표시한다.

폴더의 생성, 이름 변경, 이동, 삭제는 동일한 분류 목적을 공유하므로 단일 유스케이스에서 통합 관리한다.

폴더는 중첩 계층 구조를 지원하며 인위적인 깊이 제한을 두지 않는다.

폴더는 문서 분류 용도이며 별도의 상태나 권한을 갖지 않는다. 접근 권한은 프로젝트 단위로 적용한다([PRD 2.4](../../prd.md)).

## 대체 흐름 (Alternate Flows)

### A1 이름이 비어 있다

- **시작 조건:** 5단계에서 폴더 이름이 비어 있다.
- **처리 절차:**
  1. 시스템이 이름 입력이 필요함을 알린다.
  2. 사용자가 이름을 다시 입력한다.
  3. **기본 흐름 5로 복귀.**

### A2 동일한 이름의 폴더가 이미 존재한다

- **시작 조건:** 5단계에서 동일 상위 폴더 내 동일한 이름의 폴더가 존재한다.
- **처리 절차:**
  1. 시스템이 폴더를 정상 생성한다.
  2. **기본 흐름 6으로 복귀.**

고유 식별자로 관리하므로 동일 경로 내 폴더 이름 중복을 허용한다.

### A3 생성을 취소한다

- **시작 조건:** 3–5단계에서 사용자가 폴더 생성을 취소한다.
- **처리 절차:**
  1. 시스템이 폴더를 생성하지 않는다.
  2. **실패로 종료.**

### A4 폴더 이름을 변경한다

- **시작 조건:** 1단계 후, 사용자가 특정 폴더의 이름 변경을 요청한다.
- **처리 절차:**
  1. 사용자가 새 폴더 이름을 입력한다.
  2. 시스템이 이름의 유효성을 검증한다.
  3. 시스템이 폴더 이름을 변경하고 목록에 반영한다.
  4. **다른 성공으로 종료.**

### A5 폴더를 다른 위치로 이동한다

- **시작 조건:** 1단계 후, 사용자가 특정 폴더의 이동을 요청한다.
- **처리 절차:**
  1. 사용자가 이동 대상 상위 폴더(또는 최상위 루트)를 선택한다.
  2. 시스템이 대상 위치가 해당 폴더 자신이나 그 하위 폴더가 아님을 검증한다.
  3. 시스템이 폴더의 상위 경로 참조를 변경한다. 하위 폴더 및 문서가 함께 이동한다.
  4. **다른 성공으로 종료.**

### A6 자기 자신 또는 하위 폴더로 이동 시도

- **시작 조건:** A5 2단계에서 선택한 대상 위치가 해당 폴더 자신 또는 하위 폴더다.
- **처리 절차:**
  1. 시스템이 순환 참조 방지를 위해 해당 위치로 이동할 수 없음을 알린다.
  2. **실패로 종료.**

### A7 폴더를 삭제한다

- **시작 조건:** 1단계 후, 사용자가 특정 폴더의 삭제를 요청한다.
- **처리 절차:**
  1. 시스템이 포함된 문서 및 하위 폴더 수를 표시하고 삭제 재확인을 요청한다.
  2. 사용자가 삭제를 확정한다.
  3. 시스템이 포함된 문서와 하위 폴더를 한 단계 상위 경로로 승격한다.
  4. 시스템이 해당 폴더를 삭제하고 목록으로 복귀한다.
  5. **다른 성공으로 종료.**

폴더 삭제 시 하위 문서는 삭제하지 않고 상위 경로로 보존한다.

### A8 삭제를 취소한다

- **시작 조건:** A7 1단계 확인 화면에서 사용자가 삭제를 취소한다.
- **처리 절차:**
  1. 시스템이 폴더를 삭제하지 않는다.
  2. **실패로 종료.**

### A9 타인 프로젝트의 폴더 접근

- **시작 조건:** A4·A5·A7 단계에서 대상 폴더가 사용자의 프로젝트에 속하지 않는다.
- **처리 절차:**
  1. 시스템이 해당 리소스가 존재하지 않음을 알린다.
  2. **실패로 종료.**

보안을 위해 권한 없음 대신 리소스 부재로 응답한다.

### A10 대상 폴더가 이미 존재하지 않는다

- **시작 조건:** A5·A7 단계에서 대상 폴더가 이미 삭제되었다.
- **처리 절차:**
  1. 시스템이 해당 리소스가 존재하지 않음을 알린다.
  2. **실패로 종료.**

### A11 폴더 동시 수정 충돌

- **시작 조건:** A4·A5 단계에서 화면 진입 시점 이후 다른 세션에서 이미 수정이 완료되었다.
- 처리 절차는 해당 슬라이스 착수 시 기술한다.

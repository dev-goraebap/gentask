# DOC-010 작업 아이템 연결

- **목표:** 결정 근거가 기술된 문서와 실제 작업 아이템을 상호 연계하여 어느 한 화면에서 관련 항목을 즉시 조회할 수 있도록 한다.
- **주 액터:** 사용자
- **지원 액터:** 없음
- **트리거:** 수행할 작업의 요구사항이나 설계 근거가 문서에 기술되어 있다.

## 기본 흐름 (Basic Flow)

1. 사용자가 문서 상세 화면으로 진입한다.
2. 사용자가 작업 아이템 연결을 요청한다.
3. 시스템이 동일 프로젝트 내 작업 아이템 선택 목록을 표시한다.
4. 사용자가 연결할 작업 아이템을 선택한다.
5. 시스템이 두 항목 간의 연결 관계를 등록하고, 문서 상세 화면과 작업 아이템 상세 화면 양쪽에 링크를 표시한다.

문서와 작업 아이템의 연계는 양방향 대칭 관계이며 단일 연결 레코드로 관리한다. 어느 쪽에서 등록하든 동일하게 처리된다.

부모-자식 계층 관계([ITM-004](<../item/ITM-004(작업 아이템 편집).md>))와 달리 N:N 다대다 매핑을 지원한다.

연결 관계를 해제하더라도 문서와 작업 아이템 자체는 독립적으로 유지된다.

## 대체 흐름 (Alternate Flows)

### A1 연결을 취소한다

- **시작 조건:** 3–4단계에서 사용자가 선택을 취소한다.
- **처리 절차:**
  1. 시스템이 연결을 등록하지 않는다.
  2. **실패로 종료.**

### A2 이미 연결되어 있다

- **시작 조건:** 5단계에서 해당 문서와 작업 아이템이 이미 연결되어 있다.
- **처리 절차:**
  1. 시스템이 중복 등록 없이 이미 연결된 상태임을 안내한다.
  2. **다른 성공으로 종료.**

### A3 연결을 해제한다

- **시작 조건:** 1단계 후, 사용자가 기존 연결 링크의 해제를 요청한다.
- **처리 절차:**
  1. 시스템이 연결 관계를 해제하고 양측 화면의 목록에서 제거한다.
  2. **다른 성공으로 종료.**

데이터 유실이 없는 단순 참조 해제이므로 별도의 확인 단계를 거치지 않는다.

### A4 작업 아이템 화면에서 연결한다

- **시작 조건:** 사용자가 작업 아이템 상세 화면에서 근거 문서 연결을 요청한다.
- **처리 절차:**
  1. 시스템이 동일 프로젝트 내 문서 선택 목록을 표시한다.
  2. 사용자가 연결할 문서를 선택한다.
  3. **기본 흐름 5로 복귀.**

### A5 타 프로젝트의 항목을 지정한다

- **시작 조건:** 4단계에서 지정한 작업 아이템이 문서와 동일한 프로젝트에 속하지 않는다.
- **처리 절차:**
  1. 시스템이 해당 리소스가 존재하지 않음을 알린다.
  2. **실패로 종료.**

보안을 위해 권한 없음 대신 리소스 부재로 응답한다.

### A6 연결된 항목이 삭제된다

- **시작 조건:** 연결되어 있던 문서나 작업 아이템 중 한쪽이 삭제된다.
- **처리 절차:**
  1. 시스템이 연계 관계를 해제한다.
  2. 남아 있는 항목은 유지하고 연계 목록에서만 제거한다.
  3. **다른 성공으로 종료.**

### A7 본문 내 작업 아이템 언급

- **시작 조건:** 문서 본문에 작업 아이템 식별자가 텍스트로 기술되어 있다.
- 처리 절차는 해당 슬라이스 착수 시 기술한다.

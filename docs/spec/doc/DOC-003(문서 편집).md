# DOC-003 문서 편집

- **목표:** 변경된 내용을 문서에 반영하되 이전 개정 이력을 보존하여 변경 추적성을 유지한다.
- **주 액터:** 사용자
- **지원 액터:** 없음
- **트리거:** 문서에 기술된 내용과 현재 요구사항 간에 차이가 발생했다.

## 기본 흐름 (Basic Flow)

1. 사용자가 문서 상세 화면으로 진입한다.
2. 사용자가 문서 수정을 요청한다.
3. 시스템이 제목 및 본문 편집 입력을 활성화한다.
4. 사용자가 제목 또는 본문을 수정한다.
5. 시스템이 제목이 비어 있지 않음을 검증한다.
6. 시스템이 기존 개정 대비 변경 사항이 있는지 검증한다.
7. 시스템이 새 개정을 등록하고 문서의 최신 개정 참조를 갱신한 후 상세 조회 화면으로 이동한다.

문서 수정 시 기존 내용을 덮어쓰지 않고 신규 개정 레코드를 추가한다. 개정은 불변 데이터이며, 삭제는 [DOC-007](<./DOC-007(문서 지우기).md>)의 문서 삭제 시에만 일괄 처리한다.

내용 변경 사항이 없는 저장은 신규 개정을 생성하지 않는다.

개정 사유 입력은 선택 사항이다.

제목 변경 역시 신규 개정 이력으로 기록된다.

## 대체 흐름 (Alternate Flows)

### A1 제목이 비어 있다

- **시작 조건:** 5단계에서 제목이 비어 있다.
- **처리 절차:**
  1. 시스템이 제목 입력이 필요함을 알린다.
  2. 사용자가 제목을 다시 입력한다.
  3. **기본 흐름 5로 복귀.**

### A2 변경 사항이 없다

- **시작 조건:** 6단계에서 본문과 제목이 직전 개정과 동일하다.
- **처리 절차:**
  1. 시스템이 새 개정을 생성하지 않고 상세 조회 화면으로 이동한다.
  2. **다른 성공으로 종료.**

### A3 개정 사유를 입력한다

- **시작 조건:** 4단계 후, 사용자가 개정 사유를 함께 입력한다.
- **처리 절차:**
  1. 사용자가 단문 사유를 입력한다.
  2. **기본 흐름 5로 복귀.**

### A4 수정을 취소한다

- **시작 조건:** 3–6단계에서 사용자가 수정을 취소한다.
- **처리 절차:**
  1. 시스템이 변경 사항을 저장하지 않고 직전 개정 상태를 유지한다.
  2. **실패로 종료.**

### A5 문서가 존재하지 않는다

- **시작 조건:** 7단계에서 대상 문서가 이미 삭제되었다.
- **처리 절차:**
  1. 시스템이 해당 리소스가 존재하지 않음을 알린다.
  2. **실패로 종료.**

### A6 타인 프로젝트의 문서 수정

- **시작 조건:** 7단계에서 대상 문서가 사용자의 프로젝트에 속하지 않는다.
- **처리 절차:**
  1. 시스템이 해당 리소스가 존재하지 않음을 알린다.
  2. **실패로 종료.**

보안을 위해 권한 없음 대신 리소스 부재로 응답한다.

### A7 CLI에서 수정한다

- **시작 조건:** 2단계에서 CLI(`gentask`)로 수정을 개시한다.
- 처리 절차는 해당 슬라이스 착수 시 기술한다.

### A8 동일 문서 동시 수정 충돌

- **시작 조건:** 7단계에서 문서를 조회한 시점 이후 다른 세션에서 이미 수정이 완료되었다.
- 처리 절차는 해당 슬라이스 착수 시 기술한다.

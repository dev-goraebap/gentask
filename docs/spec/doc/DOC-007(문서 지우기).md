# DOC-007 문서 삭제

- **목표:** 더 이상 유효하지 않은 문서를 삭제하여 프로젝트 지식 베이스의 정합성을 유지한다.
- **주 액터:** 사용자
- **지원 액터:** 없음
- **트리거:** 문서가 기술하던 기능이나 정책이 폐기되어 보존할 가치가 없다.

## 기본 흐름 (Basic Flow)

1. 사용자가 문서 상세 화면으로 진입한다.
2. 사용자가 문서 삭제를 요청한다.
3. 시스템이 삭제 대상 문서를 명시하고 삭제 재확인을 요청한다.
4. 사용자가 삭제를 확정한다.
5. 시스템이 문서를 소프트 삭제(Soft Delete) 처리하고 문서 목록 화면으로 이동한다.

개정 되돌리기([DOC-005](<./DOC-005(개정 되돌리기).md>))와 구분한다. 문서 삭제는 문서 엔티티 자체를 비활성화하는 작업이다.

문서는 소프트 삭제 방식으로 처리되어 기본 목록에서 제외된다.

문서 삭제 시 하위 개정 이력도 기본 목록에서 함께 제외된다.

## 대체 흐름 (Alternate Flows)

### A1 삭제를 취소한다

- **시작 조건:** 3단계 확인 화면에서 사용자가 삭제를 취소한다.
- **처리 절차:**
  1. 시스템이 문서를 삭제하지 않는다.
  2. **실패로 종료.**

### A2 작업 아이템이 연결되어 있다

- **시작 조건:** 5단계에서 해당 문서와 연결된 작업 아이템이 존재한다.
- **처리 절차:**
  1. 시스템이 연결된 작업 아이템 목록과 개수를 확인 화면에 표시한다.
  2. 시스템이 연결 관계를 해제하고 문서를 소프트 삭제 처리한다.
  3. **기본 흐름 5로 복귀.**

작업 아이템 연계 해제는 [DOC-010](<./DOC-010(작업 아이템 잇기).md>)의 규칙을 따른다.

### A3 첨부 파일이 존재한다

- **시작 조건:** 5단계에서 문서에 첨부된 파일이 존재한다.
- 처리 절차는 해당 슬라이스 착수 시 기술한다.

### A4 이미 삭제된 문서를 삭제 시도한다

- **시작 조건:** 5단계에서 대상 문서가 이미 삭제된 상태다.
- **처리 절차:**
  1. 시스템이 해당 리소스가 존재하지 않음을 알린다.
  2. **실패로 종료.**

### A5 타인 프로젝트의 문서 삭제

- **시작 조건:** 5단계에서 대상 문서가 사용자의 프로젝트에 속하지 않는다.
- **처리 절차:**
  1. 시스템이 해당 리소스가 존재하지 않음을 알린다.
  2. **실패로 종료.**

보안을 위해 권한 없음 대신 리소스 부재로 응답한다.

### A6 삭제된 문서 복원

- **시작 조건:** 5단계 후, 사용자가 삭제된 문서의 복원을 요청한다.
- 처리 절차는 해당 슬라이스 착수 시 기술한다.

### A7 CLI에서 삭제한다

- **시작 조건:** 2단계에서 CLI(`gentask`)로 삭제를 요청한다.
- 처리 절차는 해당 슬라이스 착수 시 기술한다.

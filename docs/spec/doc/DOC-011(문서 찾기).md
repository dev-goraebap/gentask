# DOC-011 문서 검색

- **목표:** 저장된 폴더 위치를 기억하지 못하더라도 키워드 검색을 통해 기작성된 문서를 신속하게 조회한다.
- **주 액터:** 사용자
- **지원 액터:** 없음
- **트리거:** 필요한 내용이 기술된 문서의 정확한 저장 위치를 알지 못한다.

## 기본 흐름 (Basic Flow)

1. 사용자가 검색 키워드를 입력한다.
2. 시스템이 현재 프로젝트 내 문서의 제목과 본문에서 키워드를 검색한다.
3. 시스템이 일치하는 문서 목록을 소속 폴더 경로와 함께 표시한다.
4. 사용자가 검색 결과 중 하나를 선택하여 해당 문서 상세 화면으로 이동한다.

문서 검색은 서버 측에서 수행하여 데이터의 일관성과 최신성을 보장한다([PRD 2.5](../../prd.md)).

문서의 중복 식별과 컨텍스트 확인을 위해 검색 결과에 소속 폴더 경로를 함께 표시한다.

검색 범위는 현재 프로젝트 내로 한정하며, 타 프로젝트 검색은 프로젝트 전환([PRJ-002](<../project/PRJ-002(프로젝트 고르기).md>)) 후 수행한다.

## 대체 흐름 (Alternate Flows)

### A1 검색 결과가 없다

- **시작 조건:** 2단계에서 키워드와 일치하는 문서가 존재하지 않는다.
- **처리 절차:**
  1. 시스템이 검색 결과가 없음을 안내한다.
  2. **실패로 종료.**

### A2 검색어가 비어 있다

- **시작 조건:** 1단계에서 입력된 키워드가 비어 있거나 공백 문자만 포함한다.
- **처리 절차:**
  1. 시스템이 검색을 실행하지 않고 현재 화면을 유지한다.
  2. **실패로 종료.**

### A3 특정 폴더 하위로 범위를 한정한다

- **시작 조건:** 1단계에서 사용자가 특정 폴더 화면에서 검색 범위를 하위 경로로 한정한다.
- **처리 절차:**
  1. 시스템이 해당 폴더 및 하위 자손 폴더에 속한 문서만을 대상으로 검색을 수행한다.
  2. **기본 흐름 3으로 복귀.**

### A4 CLI에서 검색한다

- **시작 조건:** CLI(`gentask`)를 통해 검색 요청을 개시한다.
- **전제:** 프로젝트 컨텍스트가 설정되어 있고 인증 토큰이 유효하다([AGT-001](<../agent/AGT-001(에이전트로 작업 다루기).md>)).
- **처리 절차:**
  1. CLI 도구가 검색 키워드를 포함하여 시스템 API를 호출한다.
  2. **기본 흐름 2로 복귀.**

### A5 타인 프로젝트 검색 요청

- **시작 조건:** 2단계에서 대상 프로젝트가 사용자의 소유가 아니다.
- **처리 절차:**
  1. 시스템이 해당 리소스가 존재하지 않음을 알린다.
  2. **실패로 종료.**

보안을 위해 권한 없음 대신 리소스 부재로 응답한다.

### A6 검색 결과가 과다하다

- **시작 조건:** 3단계에서 검색 결과 건수가 단일 응답 한도를 초과한다.
- 처리 절차는 해당 슬라이스 착수 시 기술한다.

### A7 작업 아이템 통합 검색

- **시작 조건:** 1단계에서 사용자가 문서와 작업 아이템의 통합 검색을 요청한다.
- 처리 절차는 해당 슬라이스 착수 시 기술한다.

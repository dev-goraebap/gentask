# DOC-006 문서 옮기기

- **목표:** 쌓인 문서를 갈래에 맞는 자리에 두어, 찾을 때 어디를 볼지 헤매지 않는다.
- **주 액터:** 사용자
- **지원 액터:** 없음
- **트리거:** 문서가 있는 자리와 그것이 다루는 갈래가 어긋났다.

## 기본 흐름 (Basic Flow)

1. 사용자가 문서 하나를 고른다.
2. 사용자가 옮기겠다고 한다.
3. 시스템이 담을 수 있는 자리를 보인다.
4. 사용자가 옮길 자리를 고른다.
5. 시스템이 그 문서가 담긴 자리를 바꾼다.

**옮기는 것은 개정이 아니다.** 개정이 갖는 것은 문서가 말하는 바이고, 어느 폴더에 있는지는 그것과 무관하다. 자리를 옮겼다고 이력에 줄이 생기면 무엇이 바뀌었는지를 볼 때 잡음이 된다.

**본문과 제목은 건드리지 않는다.** 고치는 일은 [DOC-003](<./DOC-003(문서 편집).md>)이 갖는다.

## 대체 흐름 (Alternate Flows)

### A1 최상위로 옮긴다

- **시작 조건:** 4단계에서 사용자가 폴더가 아니라 맨 위를 고른다.
- **처리 절차:**
  1. 시스템이 그 문서를 어느 폴더에도 담기지 않은 것으로 둔다.
  2. **기본 흐름 5로 복귀.**

### A2 여럿을 한 번에 옮긴다

- **시작 조건:** 1단계에서 사용자가 문서를 여럿 고른다.
- 처리 절차는 착수할 때 쓴다. 일부만 옮겨진 경우를 어떻게 다룰지가 먼저 정해져야 한다.

### A3 옮기기를 그만둔다

- **시작 조건:** 3–4단계에서 사용자가 그만둔다.
- **처리 절차:**
  1. 시스템이 그 문서를 있던 자리에 그대로 둔다.
  2. **실패로 종료.**

### A4 옮길 자리가 없어졌다

- **시작 조건:** 5단계에서 고른 폴더가 이미 지워졌다.
- **처리 절차:**
  1. 시스템이 그 자리가 없음을 알린다.
  2. **실패로 종료.**

### A5 있던 자리로 옮긴다

- **시작 조건:** 5단계에서 고른 자리가 지금 담긴 자리와 같다.
- **처리 절차:**
  1. 시스템이 아무것도 바꾸지 않는다.
  2. **다른 성공으로 종료.**

### A6 남의 프로젝트의 문서이거나 폴더다

- **시작 조건:** 5단계에서 문서나 옮길 자리가 사용자의 프로젝트에 속하지 않는다.
- **처리 절차:**
  1. 시스템이 그 자리가 없음을 알린다.
  2. **실패로 종료.**

있으나 권한이 없다고 알리지 않는다. 그렇게 알리면 무엇이 존재하는지가 새어 나간다.

**프로젝트를 건너뛰어 옮기지 않는다.** 문서는 프로젝트에 귀속되며 옮길 수 있는 자리는 같은 프로젝트 안의 폴더뿐이다.

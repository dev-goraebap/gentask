# DOC-006 문서 이동

- **목표:** 문서를 적절한 폴더 위치로 이동하여 프로젝트 내 문서 분류 체계를 정돈한다.
- **주 액터:** 사용자
- **지원 액터:** 없음
- **트리거:** 문서의 현재 위치가 분류 기준과 일치하지 않는다.

## 기본 흐름 (Basic Flow)

1. 사용자가 문서를 선택한다.
2. 사용자가 문서 이동을 요청한다.
3. 시스템이 이동 가능한 대상 폴더 목록을 표시한다.
4. 사용자가 대상 폴더를 선택한다.
5. 시스템이 해당 문서의 저장 위치(폴더 참조)를 변경한다.

문서 이동은 개정 이력 생성 대상이 아니다. 저장 위치 변경은 문서 본문 내용의 수정과 무관하므로 개정 레코드를 추가하지 않는다.

문서 이동 시 본문과 제목은 변경하지 않는다. 내용 수정은 [DOC-003](<./DOC-003(문서 편집).md>)을 따른다.

## 대체 흐름 (Alternate Flows)

### A1 최상위로 이동한다

- **시작 조건:** 4단계에서 사용자가 폴더가 아닌 최상위 루트 경로를 선택한다.
- **처리 절차:**
  1. 시스템이 문서의 상위 폴더 참조를 null로 설정한다.
  2. **기본 흐름 5로 복귀.**

### A2 다수 문서를 일괄 이동한다

- **시작 조건:** 1단계에서 사용자가 여러 문서를 다중 선택한다.
- 처리 절차는 해당 슬라이스 착수 시 기술한다.

### A3 이동을 취소한다

- **시작 조건:** 3–4단계에서 사용자가 이동을 취소한다.
- **처리 절차:**
  1. 시스템이 기존 문서 위치를 유지한다.
  2. **실패로 종료.**

### A4 대상 폴더가 존재하지 않는다

- **시작 조건:** 5단계에서 선택한 대상 폴더가 이미 삭제되었다.
- **처리 절차:**
  1. 시스템이 해당 리소스가 존재하지 않음을 알린다.
  2. **실패로 종료.**

### A5 동일한 위치로 이동한다

- **시작 조건:** 5단계에서 선택한 위치가 현재 저장 위치와 동일하다.
- **처리 절차:**
  1. 시스템이 위치를 변경하지 않는다.
  2. **다른 성공으로 종료.**

### A6 타인 프로젝트의 문서 또는 폴더

- **시작 조건:** 5단계에서 대상 문서나 폴더가 사용자의 프로젝트에 속하지 않는다.
- **처리 절차:**
  1. 시스템이 해당 리소스가 존재하지 않음을 알린다.
  2. **실패로 종료.**

보안을 위해 권한 없음 대신 리소스 부재로 응답한다. 문서는 소속 프로젝트에 귀속되며 프로젝트 간 이동은 지원하지 않는다.

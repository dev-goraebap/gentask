# ADM-001 플랫폼 사용자 관리

- **목표:** 관리자 콘솔에서 사용자 현황 및 운영 지표를 조회하여 플랫폼 운영을 지원한다.
- **주 액터:** 관리자
- **지원 액터:** 없음
- **선행 조건:** 관리자 권한을 보유한 계정으로 로그인되어 있어야 한다.
- **트리거:** 회원 가입 현황 또는 특정 사용자 계정 정보의 조회가 필요하다.

## 기본 흐름 (Basic Flow)

1. 관리자가 관리자 콘솔의 사용자 관리 화면으로 진입한다.
2. 시스템이 등록된 사용자 목록을 최근 가입순으로 조회하여 표시한다 (순번, 프로필 이미지, 닉네임, 이메일, 가입 시각 포함).

## 대체 흐름 (Alternate Flows)

### A1 사용자를 검색한다

- **시작 조건:** 2단계에서 특정 사용자의 조회가 필요하다.
- **처리 절차:**
  1. 관리자가 검색 키워드를 입력한다.
  2. 시스템이 이메일과 닉네임에 해당 키워드가 포함된 사용자만 필터링하여 표시한다.

## 예외 흐름 (Exception Flows)

### E1 일반 사용자의 관리자 화면 접근 시도

- **시작 조건:** 1단계에서 일반 사용자 권한의 계정으로 접근을 시도한다.
- **처리 절차:**
  1. 시스템이 화면 접근을 차단하고 인가 실패(`403 Forbidden`)로 응답한다.

UI 단속뿐 아니라 서버 API 계층에서 관리자 권한을 강제한다.

## 미결

- 웹 콘솔 상에서의 관리자 권한 위임 및 변경 정책
- 리소스별 세부 권한 분리(RBAC) 체계 도입
- 관리자에 의한 계정 정지 및 강제 탈퇴 기능

## 범위 밖

개별 사용자가 작성한 작업 및 문서 데이터는 플랫폼 운영자의 임의 열람 대상에서 제외한다.

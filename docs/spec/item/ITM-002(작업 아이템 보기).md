# ITM-002 작업 아이템 조회

- **목표:** 프로젝트 내 작업 아이템의 진행 현황과 계층 구조를 통합 조회한다.
- **주 액터:** 사용자
- **지원 액터:** 없음
- **트리거:** 다음 수행 작업 선정 또는 진행 현황 파악이 필요하다.

## 기본 흐름 (Basic Flow)

1. 사용자가 프로젝트 작업 아이템 목록 화면으로 진입한다.
2. 시스템이 미완료 상태인 작업 아이템을 계층 순서로 정렬하여 조회한다.
3. 시스템이 각 항목의 식별자 · 유형 · 상태 · 제목을 표시하고, 숨김 처리된 완료 항목 수를 함께 안내한다.
4. 사용자가 목록을 확인한다.

## 대체 흐름 (Alternate Flows)

필터링 조건(A1, A2)은 상호 조합될 수 있으며, 조합마다 별도의 대체 흐름을 두지 않는다.

### A1 유형으로 필터링한다

- **시작 조건:** 2단계 후, 사용자가 특정 유형만 필터링한다.
- **처리 절차:**
  1. 사용자가 원하는 유형을 선택한다.
  2. 시스템이 선택된 유형의 작업 아이템만 목록에 표시한다.
  3. **기본 흐름 3으로 복귀.**

### A2 상태로 필터링한다

- **시작 조건:** 2단계 후, 사용자가 특정 상태만 필터링한다.
- **처리 절차:**
  1. 사용자가 원하는 상태를 선택한다.
  2. 시스템이 선택된 상태의 작업 아이템만 목록에 표시한다.
  3. **기본 흐름 3으로 복귀.**

모든 상태 필터를 해제하면 기본 미완료 목록으로 복귀한다. 필터 조건은 URL 쿼리 매개변수로 관리한다([결정-0007](../../architecture/decisions/0007-shared-software-process.md)).

### A3 상세 화면으로 진입한다

- **시작 조건:** 4단계에서 사용자가 특정 작업 아이템을 선택한다.
- **처리 절차:**
  1. 시스템이 해당 작업 아이템 상세 화면으로 이동한다.
  2. 시스템이 본문, 인수 조건 목록, 하위 작업 아이템을 표시한다.
  3. **성공으로 종료.**

인수 조건 통계(전체 개수 및 완료 개수)는 본문 마크다운 체크박스를 파싱하여 동적으로 산출한다.

### A4 목록이 비어 있다

- **시작 조건:** 2단계에서 표시할 작업 아이템이 존재하지 않는다.
- **처리 절차:**
  1. 시스템이 빈 목록 안내 메시지와 작업 아이템 추가 링크를 표시한다.
  2. **성공으로 종료.**

### A5 존재하지 않는 식별자로 접근한다

- **시작 조건:** 사용자가 현재 프로젝트에 존재하지 않는 식별자 URL로 직접 접근한다.
- **처리 절차:**
  1. 시스템이 해당 리소스가 존재하지 않음을 알린다.
  2. **실패로 종료.**

식별자는 프로젝트 범위 내에서 고유하다.

### A6 키워드로 검색한다

- **시작 조건:** 2단계 후, 사용자가 제목 또는 본문 키워드 검색을 요청한다.
- 처리 절차는 해당 슬라이스 착수 시 기술한다.

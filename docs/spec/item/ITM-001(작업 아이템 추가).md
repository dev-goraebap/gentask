# ITM-001 작업 아이템 추가

- **목표:** 해야 할 것을 프로젝트에 남겨, 무엇이 남았는지를 저장소 바깥에서 세지 않는다.
- **주 액터:** 사용자
- **지원 액터:** 없음
- **트리거:** 프로젝트에서 다룰 일이 정해졌다.

## 기본 흐름 (Basic Flow)

1. 사용자가 작업 아이템을 세우겠다고 한다.
2. 시스템이 적을 수 있게 한다.
3. 사용자가 제목을 적는다.
4. 시스템이 제목이 비어 있지 않음을 검증한다.
5. 시스템이 지금 프로젝트의 다음 번호를 매겨 작업 아이템을 세운다.
6. 시스템이 세운 것의 자리를 보여 준다.

## 대체 흐름 (Alternate Flows)

선택(A2, A3)은 서로 조합될 수 있다. 조합마다 대체 흐름을 두지 않는다.

### A1 제목이 비어 있다

- **시작 조건:** 4단계에서 제목이 비어 있다.
- **처리 절차:**
  1. 시스템이 제목이 필요함을 알린다.
  2. 사용자가 제목을 다시 적는다.
  3. **기본 흐름 4로 복귀.**
- 사용자가 세우기를 그만두면 A4로 간다.

### A2 유형을 고른다

- **시작 조건:** 3단계 뒤, 사용자가 유형을 고르겠다고 한다.
- **처리 절차:**
  1. 사용자가 Epic · Story · Task · Bug 중 하나를 고른다.
  2. 시스템이 그 유형을 작업 아이템에 붙인다.
  3. **기본 흐름 4로 복귀.**

고르지 않으면 Task 다. 유형은 담는 것을 가르지 않고 계층에서의 자리만 가르므로, 고르지 않았다고 해서 세우지 못할 이유가 없다.

### A3 본문을 적는다

- **시작 조건:** 3단계 뒤, 사용자가 본문을 적겠다고 한다.
- **처리 절차:**
  1. 사용자가 마크다운으로 본문을 적는다.
  2. **기본 흐름 4로 복귀.**

인수 조건은 본문 안의 관례로 적는다. 칸으로 강제하지 않는 것은 제목 하나만 남기려는 사람이 매번 그 자리를 지나야 하기 때문이다. 그 관례는 [결정-0007](../../architecture/decisions/0007-shared-software-process.md)이 갖는다.

### A4 세우기를 그만둔다

- **시작 조건:** 1–4단계 어디서든, 사용자가 세우기를 그만둔다.
- **처리 절차:**
  1. 시스템이 작업 아이템을 세우지 않는다.
  2. **실패로 종료.** 번호도 쓰이지 않는다.

### A5 부모 아래에 세운다

- **시작 조건:** 1단계에서 사용자가 어떤 작업 아이템을 보는 중에 그 아래에 세우겠다고 한다.
- 처리 절차는 착수할 때 쓴다. 부모를 고르는 자리가 화면에 아직 없다.

번호는 부모와 무관하게 프로젝트 안에서 평평하게 매긴다. 부모를 나중에 바꿔도 번호가 살아 있어야 하기 때문이며, 그 근거는 [결정-0007](../../architecture/decisions/0007-shared-software-process.md)이 갖는다.

# ITM-001 작업 아이템 추가

- **목표:** 프로젝트에서 수행할 작업을 등록하여 잔여 작업 현황을 체계적으로 추적한다.
- **주 액터:** 사용자
- **지원 액터:** 없음
- **트리거:** 프로젝트에서 수행할 신규 작업이 도출되었다.

## 기본 흐름 (Basic Flow)

1. 사용자가 작업 아이템 추가 화면으로 진입한다.
2. 사용자가 작업 아이템 생성을 요청한다.
3. 시스템이 입력 폼을 활성화한다.
4. 사용자가 제목을 입력한다.
5. 시스템이 제목이 비어 있지 않음을 검증한다.
6. 시스템이 프로젝트 내 다음 순번 식별자를 발급하여 작업 아이템을 생성한다.
7. 시스템이 생성된 작업 아이템 상세 화면으로 이동한다.

## 대체 흐름 (Alternate Flows)

선택적 단계(A2, A3)는 서로 조합될 수 있으며, 조합마다 별도의 대체 흐름을 생성하지 않는다.

### A1 제목이 비어 있다

- **시작 조건:** 5단계에서 제목이 비어 있다.
- **처리 절차:**
  1. 시스템이 제목 입력이 필요함을 알린다.
  2. 사용자가 제목을 다시 입력한다.
  3. **기본 흐름 5로 복귀.**

### A2 유형을 선택한다

- **시작 조건:** 4단계 후, 사용자가 유형을 선택한다.
- **처리 절차:**
  1. 사용자가 Epic · Story · Task · Bug 중 하나를 선택한다.
  2. 시스템이 해당 유형을 작업 아이템에 설정한다.
  3. **기본 흐름 5로 복귀.**

유형을 지정하지 않으면 기본값으로 Task가 적용된다.

### A3 본문을 작성한다

- **시작 조건:** 4단계 후, 사용자가 본문을 입력한다.
- **처리 절차:**
  1. 사용자가 마크다운 서식으로 본문을 작성한다.
  2. **기본 흐름 5로 복귀.**

인수 조건은 본문 내 체크박스 항목으로 기술하며, 상세 규약은 [결정-0007](../../architecture/decisions/0007-shared-software-process.md)을 따른다.

### A4 생성을 취소한다

- **시작 조건:** 1–5단계에서 사용자가 작업 아이템 생성을 취소한다.
- **처리 절차:**
  1. 시스템이 작업 아이템을 생성하지 않는다.
  2. **실패로 종료.** 순번 번호는 소모되지 않는다.

### A5 상위 작업 아이템을 지정한다

- **시작 조건:** 1단계에서 특정 작업 아이템의 하위 항목으로 추가를 요청한다.
- 처리 절차는 해당 슬라이스 착수 시 기술한다.

식별자는 계층과 무관하게 프로젝트 단위로 단일 수열 채번하며, 상하 관계는 부모 참조 필드로 관리한다([결정-0007](../../architecture/decisions/0007-shared-software-process.md)).

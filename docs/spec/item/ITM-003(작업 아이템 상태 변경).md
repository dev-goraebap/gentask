# ITM-003 작업 아이템 상태 변경

- **목표:** 작업 아이템의 진행 단계를 갱신하여 최신 작업 현황을 반영한다.
- **주 액터:** 사용자
- **지원 액터:** 없음
- **트리거:** 작업 아이템의 진행 상황에 변화가 생겼다.

## 기본 흐름 (Basic Flow)

1. 사용자가 작업 아이템 상세 화면으로 진입한다.
2. 사용자가 변경할 상태를 선택한다.
3. 시스템이 작업 아이템의 상태를 갱신한다.
4. 사용자가 변경된 상태를 확인한다.

상태는 백로그(BACKLOG) · 예정(TODO) · 진행 중(IN_PROGRESS) · 완료(DONE) · 취소(CANCELED)의 5가지로 관리하며, 세부 상태 정책은 [결정-0007](../../architecture/decisions/0007-shared-software-process.md)을 따른다.

## 대체 흐름 (Alternate Flows)

### A1 완료 또는 취소 상태로 변경한다

- **시작 조건:** 3단계에서 선택한 상태가 완료(DONE) 또는 취소(CANCELED)다.
- **처리 절차:**
  1. 시스템이 현재 시각을 종료 시각(closedAt)으로 기록한다.
  2. **기본 흐름 4로 복귀.**

### A2 종료된 항목을 미종료 상태로 복원한다

- **시작 조건:** 3단계에서 완료 또는 취소 상태였던 항목을 미종료 상태로 변경한다.
- **처리 절차:**
  1. 시스템이 종료 시각(closedAt)을 null로 초기화한다.
  2. **기본 흐름 4로 복귀.**

### A3 기존 상태와 동일한 상태를 선택한다

- **시작 조건:** 2단계에서 선택한 상태가 현재 상태와 동일하다.
- **처리 절차:**
  1. 시스템이 상태를 변경하지 않는다.
  2. **성공으로 종료.**

### A4 타인 프로젝트의 작업 아이템

- **시작 조건:** 3단계에서 대상 항목이 사용자의 프로젝트에 속하지 않는다.
- **처리 절차:**
  1. 시스템이 해당 리소스가 존재하지 않음을 알린다.
  2. **실패로 종료.**

보안을 위해 권한 없음 대신 리소스 부재로 응답한다.

### A5 미완료 하위 항목이 존재하는 부모 항목의 종료

- **시작 조건:** 3단계에서 종료하려는 작업 아이템에 미완료 상태인 하위 자식 항목이 존재한다.
- 처리 절차는 해당 슬라이스 착수 시 기술한다.

# AGT-001 에이전트 작업 관리

- **목표:** 로컬 에이전트가 CLI를 통해 사용자 계정의 작업 데이터에 접근하여 조회, 등록, 수정할 수 있도록 지원한다.
- **주 액터:** 로컬 에이전트
- **지원 액터:** 없음
- **선행 조건:** 사용자가 에이전트 인증 토큰을 발급받아 로컬 환경에 저장해 두었다([USR-003 프로필 관리](<../user/USR-003(프로필 관리).md>) A3).
- **트리거:** 사용자가 로컬 에이전트에게 작업 아이템 조회, 등록, 수정을 지시했다.

에이전트가 직접 CLI 인터페이스를 호출하여 절차를 개시하므로 주 액터를 로컬 에이전트로 정의한다.

개별 조작 단위로 분할하지 않고 에이전트 CLI 연계라는 단일 유스케이스로 통합 관리한다.

## 기본 흐름 (Basic Flow)

1. 에이전트가 설정된 API 토큰을 포함하여 시스템에 인증을 요청한다.
2. 시스템이 API 토큰의 유효성을 검증하고 소유 사용자 계정을 식별한다.
3. 에이전트가 해당 사용자의 작업 데이터를 조회, 등록, 수정, 삭제한다.
4. 시스템이 처리 결과를 반환한다.
5. 에이전트가 작업 결과를 사용자에게 알린다.

## 대체 흐름 (Alternate Flows)

### A1 토큰이 설정되어 있지 않다

- **시작 조건:** 1단계에서 CLI 환경에 설정된 API 토큰이 존재하지 않는다.
- **처리 절차:**
  1. 에이전트가 시스템 요청을 중단하고 토큰 설정이 필요함을 사용자에게 안내한다.
  2. **실패로 종료.**

### A2 토큰이 유효하지 않다

- **시작 조건:** 2단계에서 토큰 검증에 실패한다.
- **처리 절차:**
  1. 시스템이 인증 실패(`401 Unauthorized`)로 응답한다.
  2. 에이전트가 토큰 재발급이 필요함을 사용자에게 안내한다.
  3. **실패로 종료.**

보안을 위해 만료된 토큰과 미등록 토큰을 구분하지 않는다([결정-0005](../../architecture/decisions/0005-shared-authentication.md)).

### A3 타인의 작업 아이템에 접근한다

- **시작 조건:** 3단계에서 지정한 작업 아이템이 존재하지 않거나 타인의 소유다.
- **처리 절차:**
  1. 시스템이 해당 리소스가 존재하지 않음(`404 Not Found`)으로 응답한다.
  2. **실패로 종료.**

보안을 위해 권한 없음 대신 리소스 부재로 응답한다([결정-0004](../../architecture/decisions/0004-shared-error-contract.md)).

## 미결

- 에이전트의 첨부 파일 및 알림 제어 지원
- 다중 에이전트별 토큰 분리 관리([USR-003](<../user/USR-003(프로필 관리).md>) 미결 연계)

## 범위 밖

토큰 발급 UI([USR-003](<../user/USR-003(프로필 관리).md>) A3) 및 브라우저 OAuth 자동 연동은 본 유스케이스 범위에 포함하지 않는다([결정-0013](../../architecture/decisions/0013-agent-cli.md)).

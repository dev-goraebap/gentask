# 투두젠 제품 요구사항 (Product Requirements)

투두젠(todogen)은 개인용 작업(Todo) 관리 서비스입니다. 사용자는 자기 계정에 작업을 남기고, 스마트 목록으로 지금 손댈 것을 고르고, 끝낸 것을 완료된 작업으로 남깁니다. 작업에는 기한과 미리 알림과 파일을 붙일 수 있습니다. 기능 범위와 용어는 Microsoft To Do 를 기준점으로 삼습니다.

## 범위 밖

- **여럿이 함께 쓰는 것.** 공유와 위임과 권한 구분을 두지 않습니다. 데이터는 계정 단위로 격리하며 다른 계정의 작업은 존재 여부도 드러내지 않습니다.
- **작업이 아닌 것.** 일정과 노트와 문서를 다루지 않습니다. 기한과 미리 알림은 작업에 붙는 속성이며 달력이 아닙니다.
- **고가용성과 대규모 처리량.** 사용자 한 명과 서버 한 대를 전제합니다. 근거는 [1.2 품질 목표](./architecture/01-introduction-and-goals.md)가 갖습니다.

아직 열지 않았을 뿐 범위 밖이 아닌 것은 [백로그](../backlog/BACKLOG.md)의 "나중"이 갖습니다. 미리 알림을 실제로 울리는 것, 로컬 에이전트가 작업을 등록하는 것, 반복하는 작업, 작업을 묶는 목록이 거기 있습니다.

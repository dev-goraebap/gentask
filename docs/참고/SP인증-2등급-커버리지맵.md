# SP인증 2등급 커버리지 맵

SP인증 2등급(프로젝트관리·개발·지원 3개 영역)의 평가항목을 이 프로젝트의 무엇이 충족하는지 정리한 지도.
테일러링 원칙과 역할 분담의 원본은 `AGENTS.md`. 기준 전문은 이 폴더의 `SP인증기준-전문.txt` 참조.

수행 주체 표기 — 사람: 승인자 / 에이전트: 수행자 / CI: 측정자

## 영역 1 · 프로젝트 관리

| 평가항목 | 충족 수단 | 주 수행자 |
|---|---|---|
| 1.1 프로젝트 계획 | `docs/계획.md` — 목표·범위·마일스톤·완료조건·위험. 일정 대신 순서로 정의 | 사람 |
| 1.2 프로젝트 통제 | 마일스톤 종료 시 회고(`docs/회고/`) + 계획 대비 확인, 어긋나면 계획.md 수정 커밋 | 사람 + 에이전트 |
| 1.3 협력업체 관리 | 해당 없음 — 외부 조달 없는 1인 프로젝트 (테일러링 제외) | — |

## 영역 2 · 개발

| 평가항목 | 충족 수단 | 주 수행자 |
|---|---|---|
| 2.1 요구사항 관리 | `docs/요구사항/` — ID 컨벤션(AUTH-01 등), 상태 관리, 이슈·커밋·테스트에서 ID 참조로 추적성 | 사람 + 에이전트 |
| 2.2 분석 | 요구사항 문서의 인수조건(관찰 가능한 동작) + 확정 시 사람 검토 | 사람 + 에이전트 |
| 2.3 설계 | `docs/설계/`(아키텍처·DB·API) + `docs/결정기록/`(ADR, 불변) | 에이전트 초안 + 사람 결정 |
| 2.4 구현 | 코딩 표준 = 린터 설정, 준수 검토 = 린트 + 정적분석(CI 게이트), 단위·통합 테스트 | 에이전트 + CI |
| 2.5 테스트 | 인수조건 기반 시스템 테스트, 인수 판정은 사람만 | CI + 사람 |

## 영역 3 · 지원

| 평가항목 | 충족 수단 | 주 수행자 |
|---|---|---|
| 3.1 품질보증 | DoD 체크리스트(AGENTS.md) + QA 페르소나 에이전트의 별도 컨텍스트 검토 + PR 게이트 | 에이전트 + CI |
| 3.2 형상관리 | 단일 저장소 git, 형상 항목 목록(AGENTS.md), 태그=베이스라인, 태그 전 형상감사(`docs/감사/`) | 에이전트 + 사람 |
| 3.3 측정 및 분석 | CI가 커버리지·린트 위반·테스트 수 자동 수집, 마일스톤 회고에서 분석 | CI + 에이전트 |

## 문서 원칙 요약

- 원본(손으로 유지): AGENTS.md, 계획, 요구사항, 설계, 결정기록, CHANGELOG, 린터 설정
- 파생(자동 생성, 손으로 쓰지 않음): 추적 매트릭스, 진척 보고, 견적서, WBS, 측정 대장, QA 보고서, 테스트 명세서

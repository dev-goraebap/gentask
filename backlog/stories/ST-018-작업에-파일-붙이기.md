# 작업에 파일 붙이기

> 사용자로서, 작업에 관련 파일을 붙여 두고 싶다. 그 일을 할 때 찾아다니지 않기 위해.

서술서: [TSK-003 작업 편집](<../../docs/spec/task/TSK-003(작업 편집).md>) · 흐름: A11

## 인수 조건

- [ ] **AC1** When 사용자가 상세에서 파일을 붙이면, 시스템은 그 작업의 파일 목록에 이름과 크기를 보여 준다
- [ ] **AC2** If 붙임이 작업당 5개를 넘거나 각 10MB 를 넘으면, then 시스템은 그 붙임을 거절한다
- [ ] **AC3** When 붙인 파일을 받으면, 올린 그 파일이 그 이름으로 온다
- [ ] **AC4** When 파일을 떼면, 목록과 보관소에서 함께 사라진다
- [ ] **AC5** If 붙임을 거절하면, then 시스템은 사유를 알린다

## 메모

- presigned PUT 으로 올리고 presigned GET 으로 받는다. 백엔드는 URL 만 주고, 붙임 확정 시 보관소의 실제 크기를 확인해 제한을 강제한다
- 프론트는 uppy(Dashboard + AwsS3) 를 쓴다. 제한(5개 · 10MB)은 uppy 에도 걸어 일찍 알리되, 강제는 서버가 한다
- 로컬 보관소는 compose 의 MinIO 다. R2 로 갈 때는 접속 프로퍼티만 바꾼다 — devkit 로컬 설정에 R2 키가 실재하지 않아(주석뿐) 로컬 S3 호환으로 세웠다

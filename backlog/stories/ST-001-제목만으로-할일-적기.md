# 제목만으로 할일 적기

> 사용자로서, 떠오른 일을 제목만 적어 남기고 싶다. 잊지 않기 위해.

서술서: [TK-001 할일 적어두기](<../../docs/1.analysis/작업/TK-001(할일 적어두기).md>) · 흐름: BF, A1, A5, A7

## 인수 조건

- [ ] When 사용자가 제목을 적고 확정하면, 시스템은 그 할일을 목록에 넣는다
- [ ] If 제목이 비어 있거나 공백뿐이면, then 시스템은 할일을 넣지 않고 아무것도 알리지 않는다
- [ ] When 사용자가 적기를 그만두면, 시스템은 목록을 그대로 둔다
- [ ] While 사용자가 특정 묶음(오늘 · 중요 · 기한)을 보는 중에 적으면, 시스템은 그 묶음의 성질을 붙여 넣는다

Story 는 목이 아니라 실제 백엔드 연결로 인수 조건을 확인했을 때 닫는다. 목 위의 화면 테스트(`TK-001 S*:` 이름)는 프론트 경로까지 참이라는 뜻이다.

## 메모

프론트:

- 등록 버튼이 없다. Enter 가 확정이다. 조합 중의 Enter 는 입력기가 받으므로 확정이 아니다.
- 빈 입력란은 오류가 아니라 기본 상태다. 검증 표시를 두지 않는다.
- 묶음 안에서 적으면 화면이 그 묶음의 조건을 씨앗(`TaskSeed`)으로 넘기고 저장소가 그대로 담는다.

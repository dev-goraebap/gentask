# 완료되지 않은 작업 보기

> 사용자로서, 완료되지 않은 작업을 보고 싶다. 다음에 할 일을 고르기 위해.

서술서: [TK-002 작업 보기](<../../docs/1.analysis/유스케이스/TK-002(작업 보기).md>) · 흐름: BF, A5, A7

## 인수 조건

- [ ] When 사용자가 목록을 열면, 시스템은 완료되지 않은 작업만 보여 준다
- [ ] If 해당하는 작업이 없으면, then 시스템은 고를 일이 없음을 알리고 다음 행동을 안내한다
- [ ] If 사용자가 모르는 스마트 목록을 요청하면, then 시스템은 완료되지 않은 작업 전체를 보여 준다

Story 는 목이 아니라 실제 백엔드 연결로 인수 조건을 확인했을 때 닫는다. 목 위의 화면 테스트(`TK-002 S*:` 이름)는 프론트 경로까지 참이라는 뜻이다.

## 메모

프론트:

- 빈 목록은 오류가 아니다. 콘텐츠 영역 안에 안내 문장을 둔다. 06-layout.md 5.4절.
- 주소의 스마트 목록 값이 모르는 것이면 전체로 되돌린다.

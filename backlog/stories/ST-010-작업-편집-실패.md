# 작업 편집 실패

> 사용자로서, 편집하지 못했으면 알고 싶다. 편집된 줄 알고 지나치지 않기 위해.

서술서: [TSK-003 작업 편집](<../../docs/spec/task/TSK-003(작업 편집).md>) · 흐름: A8

## 인수 조건

- [ ] **AC1** If 편집하려는 작업이 없으면, then 시스템은 찾을 수 없음을 알린다
- [ ] **AC2** If 편집하려는 작업이 없으면, then 시스템은 목록으로 돌아가는 수단을 보여 준다

Story 는 목이 아니라 실제 백엔드 연결로 인수 조건을 확인했을 때 닫는다. 목 위의 화면 테스트(`ST-010 AC*:` 이름)는 프론트 경로까지 참이라는 뜻이다.

## 메모

프론트:

- 거부되면 토스트로 알리고 폼을 이전 값으로 되돌린다. 화면과 저장소가 다른 값을 보이지 않게 한다.
- 목 스토어는 실패하지 않는다.

백엔드:

- 제목 200자(`TaskTitle.MAX`) · 메모 2000자(`TaskNote.MAX`)가 상한이다. TSK-003 의 미결이던 데이터 제약이 여기서 정해졌다.

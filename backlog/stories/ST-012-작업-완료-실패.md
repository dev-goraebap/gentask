# 작업 완료 실패

> 사용자로서, 완료하지 못했으면 알고 싶다. 완료한 줄 알고 잊지 않기 위해.

서술서: [TK-004 작업 완료](<../../docs/1.analysis/유스케이스/TK-004(작업 완료).md>) · 흐름: A1, A3, A4

## 인수 조건

- [ ] If 이미 완료된 작업을 다시 완료하면, then 시스템은 완료한 시각을 바꾸지 않는다
- [ ] If 완료하려는 작업이 없으면, then 시스템은 아무것도 바꾸지 않는다
- [ ] If 저장소가 갱신을 거부하면, then 시스템은 완료하지 못했음을 알리고 완료 전 상태를 보여 준다

Story 는 목이 아니라 실제 백엔드 연결로 인수 조건을 확인했을 때 닫는다. 목 위의 화면 테스트(`TK-004 S*:` 이름)는 프론트 경로까지 참이라는 뜻이다.

## 메모

프론트:

- 이미 완료됨과 없는 대상은 화면에서 만들 수 없다. 저장소 수준에서 확인한다.
- 거부되면 토스트로 알리고 체크박스를 누르기 전으로 되돌린다. 체크박스는 자기 표시를 갖고 입력값이 그대로면 다시 그리지 않으므로 그 표시를 직접 되돌린다.

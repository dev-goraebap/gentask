# 작업 완료 실패

> 사용자로서, 완료하지 못했으면 알고 싶다. 완료한 줄 알고 잊지 않기 위해.

서술서: [TSK-004 작업 완료](<../../docs/spec/task/TSK-004(작업 완료).md>) · 흐름: A1, A3

## 인수 조건

- [ ] **AC1** [서버] If 이미 완료된 작업을 다시 완료하면, then 시스템은 완료한 시각을 바꾸지 않는다
- [ ] **AC2** [서버] If 완료하려는 작업이 없으면, then 시스템은 아무것도 바꾸지 않는다

Story 는 목이 아니라 실제 백엔드 연결로 인수 조건을 확인했을 때 닫는다. 목 위의 화면 테스트(`ST-012 AC*:` 이름)는 프론트 경로까지 참이라는 뜻이다.

## 메모

프론트:

- 이미 완료됨과 없는 대상은 화면에서 만들 수 없다. 저장소 수준에서 확인한다.
- 거부되면 토스트로 알리고 체크박스를 누르기 전으로 되돌린다. 체크박스는 자기 표시를 갖고 입력값이 그대로면 다시 그리지 않으므로 그 표시를 직접 되돌린다.

# 작업 속성 편집

> 사용자로서, 메모 · 기한 · 중요 · 나의 하루 추가를 바꾸고 싶다. 작업을 지금 아는 것과 같게 만들기 위해.

서술서: [TK-003 작업 편집](<../../docs/1.analysis/유스케이스/TK-003(작업 편집).md>) · 흐름: BF, A2, A3, A4, A5

## 인수 조건

- [ ] When 사용자가 메모를 편집하고 벗어나면, 시스템은 편집한 메모를 반영한다
- [ ] When 사용자가 기한을 고르거나 떼면, 시스템은 즉시 반영한다
- [ ] When 사용자가 중요 표시를 바꾸면, 시스템은 즉시 반영한다
- [ ] When 사용자가 나의 하루에 추가하거나 빼면, 시스템은 즉시 반영한다

Story 는 목이 아니라 실제 백엔드 연결로 인수 조건을 확인했을 때 닫는다. 목 위의 화면 테스트(`TK-003 S*:` 이름)는 프론트 경로까지 참이라는 뜻이다.

## 메모

프론트:

- 속성마다 편집한 즉시 반영한다.
- 나의 하루 추가됨은 boolean 이 아니라 담은 날짜다. 어제 담은 것은 오늘의 나의 하루가 아니다. 자정에 비우는 장치를 두지 않기 위해서다.
- 중요 표시는 목록 행의 별과 상세 둘 다에서 바꾼다.

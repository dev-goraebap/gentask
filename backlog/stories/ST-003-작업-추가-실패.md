# 작업 추가 실패

> 사용자로서, 저장이 안 되면 알고 싶다. 적은 줄 알고 잊지 않기 위해.

서술서: [TK-001 작업 추가](<../../docs/1.analysis/유스케이스/TK-001(작업 추가).md>) · 흐름: BF, A6

## 인수 조건

- [ ] If 저장소가 작업을 넣지 못하면, then 시스템은 남기지 못했음을 알리고 목록을 그대로 둔다
- [ ] If 넣지 못했으면, then 시스템은 적은 제목을 입력란에 남겨 둔다
- [ ] When 사용자가 다시 시도하면, 시스템은 같은 제목으로 다시 넣는다

Story 는 목이 아니라 실제 백엔드 연결로 인수 조건을 확인했을 때 닫는다. 목 위의 화면 테스트(`TK-001 S*:` 이름)는 프론트 경로까지 참이라는 뜻이다.

## 메모

- 토스트로 알리고 "다시 시도" 액션을 준다. 15-error-handling.md 3.2절.

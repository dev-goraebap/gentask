# 작업 완료

> 사용자로서, 완료한 작업을 표시하고 싶다. 남은 일만 보기 위해.

서술서: [TK-004 작업 완료](<../../docs/1.analysis/유스케이스/TK-004(작업 완료).md>) · 흐름: BF, A2

## 인수 조건

- [ ] When 사용자가 작업을 완료했다고 하면, 시스템은 그것을 완료되지 않은 작업 목록에서 빼고 완료된 작업로 남긴다
- [ ] When 사용자가 완료를 취소하면, 시스템은 그것을 완료되지 않은 작업 목록에 다시 보여 준다

Story 는 목이 아니라 실제 백엔드 연결로 인수 조건을 확인했을 때 닫는다. 목 위의 화면 테스트(`TK-004 S*:` 이름)는 프론트 경로까지 참이라는 뜻이다.

## 메모

프론트:

- 완료는 목록 행의 체크박스다. 완료된 작업의 체크박스는 되돌리기다.
- 완료 여부는 boolean 이 아니라 완료한 시각이다. 완료된 작업 목록의 순서가 그 시각이다.

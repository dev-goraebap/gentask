# 작업 삭제

> 사용자로서, 하지 않기로 한 일을 목록에서 치우고 싶다. 목록이 현실과 같게 하기 위해.

서술서: [TSK-005 작업 삭제](<../../docs/spec/task/TSK-005(작업 삭제).md>) · 흐름: BF, A1

## 인수 조건

- [ ] **AC1** When 사용자가 삭제하겠다고 하면, 시스템은 되돌릴 수 없음을 확인받는다
- [ ] **AC2** If 사용자가 확인하지 않으면, then 시스템은 작업을 그대로 둔다
- [ ] **AC3** When 사용자가 확인하면, 시스템은 작업을 목록에서 뺀다

Story 는 목이 아니라 실제 백엔드 연결로 인수 조건을 확인했을 때 닫는다. 목 위의 화면 테스트(`ST-009 AC*:` 이름)는 프론트 경로까지 참이라는 뜻이다.

## 메모

프론트:

- 지우기는 상세 안에만 있다. 목록 행에 두면 파괴적 조작이 줄마다 노출된다.
- 확인 대화를 거친다. 되살리기를 두지 않으므로 확인이 유일한 안전장치다. 07-adaptive-ui.md 의 확인 대화 예외.

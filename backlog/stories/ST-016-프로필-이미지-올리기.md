# 프로필 이미지 올리기

> 사용자로서, 아바타 자리에 내 이미지를 두고 싶다.

서술서: [TK-006 프로필 관리](<../../docs/1.analysis/유스케이스/TK-006(프로필 관리).md>) · 흐름: A1, A2, A4

## 인수 조건

- [ ] When 사용자가 이미지를 올리면, 시스템은 아바타 자리에 그 이미지를 보여 준다
- [ ] 이미지가 아니거나 10MB 를 넘으면, 시스템은 사유를 알리고 올리지 않는다
- [ ] When 이미지를 지우면, 시스템은 기본 아바타로 되돌린다

## 메모

- 업로드는 uppy 를 쓰고 presigned PUT 정석 경로를 탄다. 백엔드는 URL 만 준다
- 표시용 주소도 presigned GET 이다. 버킷을 공개로 두지 않는다

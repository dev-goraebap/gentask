# 스마트 목록으로 작업 보기

> 사용자로서, 오늘 · 중요 · 기한 · 완료된 것으로 나눠 보고 싶다. 지금 손댈 일을 빨리 고르기 위해.

서술서: [TSK-002 작업 보기](<../../docs/spec/task/TSK-002(작업 보기).md>) · 흐름: BF, A1, A2, A3, A4

## 인수 조건

- [ ] **AC1** When 사용자가 완료된 작업 스마트 목록을 고르면, 시스템은 완료된 작업만 보여 준다
- [ ] **AC2** When 사용자가 나의 하루 목록을 고르면, 시스템은 나의 하루에 추가된 완료되지 않은 작업만 보여 준다
- [ ] **AC3** When 사용자가 중요 목록을 고르면, 시스템은 중요하다고 표시한 완료되지 않은 작업만 보여 준다
- [ ] **AC4** When 사용자가 계획된 일정 목록을 고르면, 시스템은 기한이 있는 완료되지 않은 작업만 보여 준다

Story 는 목이 아니라 실제 백엔드 연결로 인수 조건을 확인했을 때 닫는다. 목 위의 화면 테스트(`ST-005 AC*:` 이름)는 프론트 경로까지 참이라는 뜻이다.

## 메모

프론트:

- 스마트 목록은 경로 파라미터(`/tasks/:view`)다. 열려 있던 상세는 쿼리 파라미터라 그대로 남는다. 08-routing.md 3절.
- 완료된 작업은 별도 스마트 목록이 아니라 같은 화면 아래의 접힌 목록이다. 펼침은 `?done=1`.
- 한 작업이 여러 스마트 목록에 동시에 나타난다. 스마트 목록은 고르기만 하고 소유하지 않는다.

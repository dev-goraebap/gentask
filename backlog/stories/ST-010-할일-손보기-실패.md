# 할일 손보기 실패

> 사용자로서, 고치지 못했으면 알고 싶다. 고쳐진 줄 알고 지나치지 않기 위해.

서술서: [TK-003 할일 손보기](<../../docs/1.analysis/작업/TK-003(할일 손보기).md>) · 흐름: A8, A9

## 인수 조건

- [ ] If 손보려는 할일이 없으면, then 시스템은 찾을 수 없음을 알리고 돌아갈 길을 보여 준다
- [ ] If 저장소가 갱신을 거부하면, then 시스템은 바꾸지 못했음을 알리고 이전 값을 보여 준다

Story 는 목이 아니라 실제 백엔드 연결로 인수 조건을 확인했을 때 닫는다. 목 위의 화면 테스트(`TK-003 S*:` 이름)는 프론트 경로까지 참이라는 뜻이다.

## 메모

프론트:

- 거부되면 토스트로 알리고 폼을 이전 값으로 되돌린다. 화면과 저장소가 다른 값을 보이지 않게 한다.
- 목 스토어는 실패하지 않는다.

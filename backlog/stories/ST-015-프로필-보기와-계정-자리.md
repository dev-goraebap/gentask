# 프로필 보기와 계정 자리

> 사용자로서, 내 계정이 나를 알아보게 하고 어디서든 그 자리로 가고 싶다.

서술서: [TK-006 프로필 관리](<../../docs/1.analysis/유스케이스/TK-006(프로필 관리).md>) · 흐름: BF, A4

## 인수 조건

- [ ] 시스템은 프로필에 아바타와 기본 정보(이메일 · 별명 · 가입일)를 보여 준다
- [ ] 이미지가 없으면 시스템은 기본 아바타(이니셜)를 보여 준다
- [ ] When 사용자가 별명을 고치면, 시스템은 프로필과 사이드바의 표시를 함께 갱신한다
- [ ] 넓은 화면에서는 사이드바 하단에 내 프로필이 고정되어 있고, 그것이 프로필로 가는 길이다
- [ ] 좁은 화면의 하단 탭은 할일 · 계정 둘이며, 할일 화면에서 사이드바를 열어 스마트 목록을 고를 수 있다

## 메모

- 하단 탭에 스마트 목록 넷을 눕힌 지금 구성은 계정이 들어올 자리가 없다. 탭은 최상위 구획(할일 · 계정)만 갖고, 스마트 목록은 열어 보는 사이드바(드로어)로 옮긴다
- 프로필 경로는 /account 다. 셸 안의 화면이며 상세 aside 는 쓰지 않는다

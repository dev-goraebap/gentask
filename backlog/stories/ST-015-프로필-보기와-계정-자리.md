# 프로필 보기와 계정 자리

> 사용자로서, 내 계정이 나를 알아보게 하고 어디서든 그 자리로 가고 싶다.

서술서: [USR-003 프로필 관리](<../../docs/spec/user/USR-003(프로필 관리).md>) · 흐름: BF

## 인수 조건

- [ ] **AC1** 시스템은 프로필에 아바타를 보여 준다
- [ ] **AC2** If 이미지가 없으면, then 시스템은 기본 아바타(이니셜)를 보여 준다
- [ ] **AC3** When 사용자가 별명을 고치면, 시스템은 프로필의 표시를 갱신한다
- **AC4** (결번)
- **AC5** (결번)
- [ ] **AC6** 시스템은 프로필에 이메일과 별명과 가입일을 보여 준다
- [ ] **AC7** When 사용자가 별명을 고치면, 시스템은 사이드바의 표시를 갱신한다
- [ ] **AC8** When 사용자가 사이드바 하단의 내 프로필을 고르면, 시스템은 프로필 화면을 보여 준다
- **AC9** (결번)

AC4 · AC5 · AC9 는 화면 폭에 따른 배치 분기였다. 배치는 인수 조건이 아니므로 걷었다. [결정-0008](<../../docs/architecture/decisions/0008-shared-testing.md>).

## 메모

- 하단 탭에 스마트 목록 넷을 눕힌 지금 구성은 계정이 들어올 자리가 없다. 탭은 최상위 구획(할일 · 계정)만 갖고, 스마트 목록은 열어 보는 사이드바(드로어)로 옮긴다
- 프로필 경로는 /account 다. 셸 안의 화면이며 상세 aside 는 쓰지 않는다

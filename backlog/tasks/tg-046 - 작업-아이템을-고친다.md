## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
서술서: ITM-004 · 흐름: BF, A1, A2, A3, A4

인수 조건은 본문 안의 체크 항목이므로 본문을 고치는 것이 곧 인수 조건을 고치는 것이다. 번호와 상태는 이 자리가 다루지 않는다.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 When 사용자가 제목과 본문을 고쳐 담으면, 시스템은 고친 것을 그 항목에 남긴다
- [ ] #2 When 사용자가 본문의 체크 항목을 고치면, 시스템은 바뀐 인수 조건을 그대로 읽는다
- [ ] #3 If 제목이 비어 있으면, then 시스템은 이름이 필요함을 알리고 고치기 전의 것을 그대로 둔다
- [ ] #4 When 사용자가 고치기를 그만두면, 시스템은 고치기 전의 것을 그대로 둔다
- [ ] #5 When 사용자가 유형을 바꾸면, 시스템은 번호를 그대로 두고 유형만 바꾼다
- [ ] #6 [서버] If 사용자의 프로젝트에 속하지 않는 항목이면, then 시스템은 그 자리가 없음을 알린다
<!-- AC:END -->

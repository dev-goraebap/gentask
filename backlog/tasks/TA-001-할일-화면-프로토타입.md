# 할일 화면 프로토타입

네 유스케이스의 화면을 목 스토어 위에 만든다. 발견 에픽 [EP-001](../epics/EP-001-할일-목록-탐색.md)의 스파이크다.

## 완료 조건

- 네 유스케이스의 화면을 다듬을 것이 없다고 판단한다. 무엇을 다듬을지는 아래 "남은 질문" 이 갖는다.
- ST-001 ~ ST-012 의 경로를 목 위에서 전부 밟을 수 있다.
- `TaskStore` 인터페이스(`web/src/entities/task/api/task-store.ts`)가 API 계약 초안으로 확정된다. 백엔드는 이 모양을 구현한다.

## 현재

- 네 유스케이스의 기본 경로와 대체 경로 대부분이 화면에 있다. 화면 테스트 136개가 통과한다.
- ST-002 마감일 있는 할일 적기의 화면은 없다.
- 목 스토어는 실패를 내지 못한다. ST-003 · ST-010 · ST-012 의 실패 경로는 테스트로만 확인했다.

## 남은 질문

발견 트랙의 항목은 스토리가 아니라 질문이다. 답이 나오면 서술서나 Story 메모에 적고 지운다.

- 적는 자리에 마감일 입력을 항상 노출하는가, 펼침으로 두는가.

## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
> 사용자로서, 이 기기로 알림을 받고 싶다. 목록을 열어 보지 않아도 정한 시각을 놓치지 않기 위해.

서술서: NTF-001 · 흐름: BF, A1, A2, A3, E1

## 메모

- 받을 자리는 기기마다 선다. 한 사람이 여럿을 가질 수 있으므로 계정에 하나가 아니라 목록이다
- 브라우저는 한 번 거절한 권한을 다시 묻지 않는다. 시스템이 되돌릴 수 없으므로 A1 은 안내로 끝난다
- VAPID 키 쌍은 서버가 갖고 공개 키만 화면에 내려간다. 키의 보관은 배포 설정이 갖는다
- A4(죽은 자리를 거둔다)는 보내는 쪽에서만 알 수 있으므로 TG-007.02 가 갖는다
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 When 사용자가 알림을 켜고 권한을 허용하면, 시스템은 이 기기를 받을 자리로 등록한다
- [ ] #2 When 등록이 끝나면, 시스템은 이 기기가 알림을 받는 상태임을 보여 준다
- [ ] #3 If 사용자가 권한을 거절하면, then 시스템은 브라우저 설정에서 다시 허용할 수 있음을 알린다
- [ ] #4 When 사용자가 알림을 끄면, 시스템은 이 기기의 받을 자리를 거둔다
- [ ] #5 When 다른 기기에서 켜면, 시스템은 앞의 기기와 나란히 등록한다
- [ ] #6 If 브라우저가 웹 푸시를 지원하지 않으면, then 시스템은 이 기기에서 받을 수 없음을 알린다
- [ ] #7 If 이 기기의 받을 자리가 서버에 없으면, then 시스템은 브라우저에 구독이 남아 있어도 받지 않는 상태로 보여 준다
<!-- AC:END -->

## Description

> 사용자로서, 내 계정으로 돌아오고 싶다. 어느 자리에서든 내 목록을 보기 위해.

서술서: USR-002 · 흐름: BF, A1, A2

## 메모

- 세션 테이블과 쿠키 속성은 TG-026 계정 만들기의 메모가 갖는다. 같은 기반 위에 선다
- 계정이 없는 경우도 자격 불일치와 같은 흐름을 탄다. 구분해 알리면 그 차이가 곧 그 이메일로 가입된 계정이 있다는 정보가 된다
- 인증이 필요한 라우트는 가드가 지키고, 세션이 도중에 풀리면 401 인터셉터가 로그인 자리로 보낸다

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 When 사용자가 맞는 자격으로 로그인하면, 시스템은 그 계정의 작업 목록을 보여 준다
- [ ] #2 When 자격이 맞지 않으면, 시스템은 어느 쪽이 틀렸는지 구분하지 않고 알린다
- [ ] #3 [서버] If 로그인하지 않았으면, then 시스템은 작업 API 접근을 거절한다
<!-- AC:END -->

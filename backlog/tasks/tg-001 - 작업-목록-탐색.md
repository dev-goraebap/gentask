## Description

발견(discovery) 에픽이다. 기획의 틀을 잡기 전에 네 유스케이스(추가 · 보기 · 편집 · 완료)의 화면을 목 위에 만들어 보고, 그 결과로 서술서와 API 계약을 확정한다. 전달(delivery)은 이 에픽이 닫힌 뒤 `TG-002 작업 목록 첫 동작` 이 맡는다.

## 완료 조건

- 네 유스케이스의 화면이 확정된다. 더 다듬을 것이 없다고 판단한 시점이다.
- 서술서(TSK-001 ~ TSK-004)의 흐름이 화면과 맞는다. 화면에서 바뀐 동작은 서술서에 반영되어 있다.
- `TaskStore` 인터페이스(`web/src/entities/task/api/task-store.ts`)가 API 계약 초안으로 확정된다.
- 남은 질문이 서술서의 미결 절이나 Draft 로 서 있다.

## 닫힌 뒤

1. `TG-002 작업 목록 첫 동작` (전달 에픽)을 만들고 TG-014 ~ TG-025 의 `parent` 를 그것으로 둔다.
2. 발견 중 바뀐 흐름만큼 Story 의 인수 조건을 고친다.
3. 백엔드 Task 를 세운다.

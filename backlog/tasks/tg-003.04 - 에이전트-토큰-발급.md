## Description

> 사용자로서, 내 에이전트가 내 계정으로 일할 토큰을 만들고 싶다. 로컬 에이전트에 MCP 를 붙이기 위해.

서술서: USR-003 · 흐름: A3

## 메모

- devkit 에는 PAT 개념이 없어(세션 토큰의 Bearer 재사용뿐) 전용 테이블(api_tokens)을 새로 둔다. 계정당 하나, 만료 없음, 재발급이 곧 교체다
- 저장은 세션과 같은 HMAC-SHA256 해시다. 원문은 발급 응답에만 실린다
- MCP 서버 자체는 후속이다. 이 Story 는 토큰이 성립하는 데까지다

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 When 사용자가 토큰을 발급하면, 시스템은 토큰 값을 그 자리에서 한 번 보여 준다
- [ ] #2 [서버] When 다시 발급하면, 시스템은 이전 토큰을 무효로 만든다
- [ ] #3 [서버] When 발급한 토큰을 `Authorization: Bearer` 로 실으면, 시스템은 작업 API 인증을 허용한다
- [ ] #4 [서버] When 토큰을 지우면, 시스템은 그 토큰의 접근을 끊는다
- [ ] #5 When 토큰 발급 화면을 다시 열면, 시스템은 토큰 값 없이 발급 사실만 보여 준다
<!-- AC:END -->

# 작업 화면 프로토타입

네 유스케이스의 화면을 목 스토어 위에 만든다. 발견 에픽 [EP-001](../epics/EP-001-작업-목록-탐색.md)의 스파이크다.

## 완료 조건

- 네 유스케이스의 화면을 다듬을 것이 없다고 판단한다. 무엇을 다듬을지는 아래 "남은 질문" 이 갖는다.
- ST-001 ~ ST-013 의 경로를 목 위에서 전부 밟을 수 있다.
- `TaskStore` 인터페이스(`web/src/entities/task/api/task-store.ts`)가 API 계약 초안으로 확정된다. 백엔드는 이 모양을 구현한다.

## 현재

- 네 유스케이스의 기본 경로와 대체 경로 대부분이 화면에 있다.
- 적는 자리가 상자가 되었고 그 안의 아이콘 줄에서 기한(ST-002)과 미리 알림(ST-013)을 붙인다.
- 목 스토어는 실패를 내지 못한다. ST-010 · ST-012 의 실패 경로는 테스트로만 확인했다.

## 남은 질문

없다. 화면에서 정하지 못한 것은 서술서 TSK-002 · TSK-003 의 미결 절로 옮겼고, 해당 슬라이스에 착수할 때 정한다.

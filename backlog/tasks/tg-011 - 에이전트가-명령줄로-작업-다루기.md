## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
MCP 서버를 걷고 같은 일을 명령줄 도구로 한다. 서버에 더할 것은 없고 AGT-001 의 흐름도 그대로이며, 에이전트가 붙는 수단만 바뀐다. 근거는 결정-0013 이 갖는다.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 [서버] When 에이전트가 저장된 토큰으로 작업을 남기면, 시스템은 그 토큰의 주인 계정에 그 작업을 만든다
- [ ] #2 [서버] When 에이전트가 목록을 요청하면, 시스템은 그 주인의 작업만 낸다
- [ ] #3 [서버] When 에이전트가 작업의 속성을 고치면, 시스템은 그 변경을 반영한다
- [ ] #4 [서버] When 에이전트가 작업을 거두면, 시스템은 그것을 지운다
- [ ] #5 [서버] If 토큰이 유효하지 않으면, then 시스템은 거절하고 에이전트는 다시 발급해야 함을 알린다
- [ ] #6 [서버] If 토큰이 저장되어 있지 않으면, then 에이전트는 붙지 않고 토큰을 두어야 함을 알린다
- [ ] #7 [서버] If 가리키는 작업이 그 주인의 것이 아니면, then 시스템은 없는 것과 같이 답한다
- [ ] #8 [서버] When 사용자가 토큰을 저장하면, 시스템은 소유자만 읽을 수 있는 파일에 그것을 둔다
- [ ] #9 [서버] If 환경변수와 저장된 파일에 토큰이 모두 있으면, then 환경변수의 것을 쓴다
<!-- AC:END -->

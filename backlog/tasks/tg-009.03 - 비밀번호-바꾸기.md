## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
> 사용자로서, 쓰던 비밀번호를 갈고 싶다. 그것을 남이 알게 되었을 때 계정을 도로 나만의 것으로 만들기 위해.

서술서: USR-006 · 흐름: 기본 · A1 · A2 · A3

## 메모

- 현재 비밀번호를 다시 받는다. 로그인 상태만으로 바꾸게 하면 자리를 비운 사이 남이 그 화면을 열어 주인을 밀어낼 수 있다
- 지금 쓰는 자리는 남기고 나머지 세션만 거둔다. 현재 비밀번호를 아는 채 지나는 경로라 조작하는 사람이 주인임이 확인된다
- API 토큰은 남긴다. 그것을 거두는 자리는 재설정이며 그 경로만이 앞선 자리들을 의심할 근거를 갖는다
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 When 사용자가 현재 비밀번호와 새 비밀번호를 제출하면, 시스템은 비밀번호를 바꾼다
- [ ] #2 When 비밀번호를 바꾸면, 시스템은 지금 쓰는 자리의 로그인을 유지한다
- [ ] #3 [서버] When 비밀번호를 바꾸면, 시스템은 지금 쓰는 자리를 뺀 나머지 세션을 거둔다
- [ ] #4 If 현재 비밀번호가 맞지 않으면, then 시스템은 맞지 않음을 알리고 아무것도 바꾸지 않는다
- [ ] #5 If 새 비밀번호가 규칙에 맞지 않으면, then 시스템은 충족하지 못한 조건을 알린다
- [ ] #6 If 새 비밀번호가 지금 것과 같으면, then 시스템은 달라야 함을 알린다
<!-- AC:END -->

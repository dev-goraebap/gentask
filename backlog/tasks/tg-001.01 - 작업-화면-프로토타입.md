## Description

네 유스케이스의 화면을 목 스토어 위에 만든다. 발견 에픽 TG-001의 스파이크다.

## 완료 조건

- 네 유스케이스의 화면을 다듬을 것이 없다고 판단한다. 무엇을 다듬을지는 아래 "남은 질문" 이 갖는다.
- TG-002.01 ~ TG-002.12 의 경로를 목 위에서 전부 밟을 수 있다.
- `TaskStore` 인터페이스(`web/src/entities/task/api/task-store.ts`)가 API 계약 초안으로 확정된다. 백엔드는 이 모양을 구현한다.

## 현재

- 네 유스케이스의 기본 경로와 대체 경로 대부분이 화면에 있다.
- 적는 자리가 상자가 되었고 그 안의 아이콘 줄에서 기한(TG-002.02)과 미리 알림(TG-002.12)을 붙인다.
- 목 스토어는 실패를 내지 못한다. TG-002.09 · TG-002.11 의 실패 경로는 테스트로만 확인했다.

## Description

> 사용자로서, 제목을 편집하고 싶다. 지금 아는 것과 같게 만들기 위해.

서술서: TSK-003 · 흐름: BF, A1, A7

Story 는 목이 아니라 실제 백엔드 연결로 인수 조건을 확인했을 때 닫는다. 목 위의 화면 테스트(`TG-019 AC*:` 이름)는 프론트 경로까지 참이라는 뜻이다.

## 메모

프론트:

- 저장 버튼이 없다. 벗어나면 반영한다. 12-forms.md.
- 그만두기는 Esc 다. 벗어나면 반영되므로 벗어나기 전에 되돌릴 자리가 필요했다. 제목과 메모 둘 다 받는다.

관련 커밋: fbee36f, 4655640

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 When 사용자가 제목을 편집하고 입력란을 벗어나거나 Enter 를 누르면, 시스템은 편집한 제목을 반영한다
- [ ] #2 If 편집한 제목이 비어 있으면, then 시스템은 반영하지 않는다
- [ ] #3 When 사용자가 편집하다 그만두면, 시스템은 편집하던 제목을 반영하지 않는다
- [ ] #4 If 편집한 제목이 비어 있으면, then 시스템은 사유를 보여 준다
<!-- AC:END -->

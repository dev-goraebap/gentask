## Description

> 사용자로서, 아바타 자리에 내 이미지를 두고 싶다.

서술서: USR-003 · 흐름: A1, A2, A4

## 메모

- 업로드는 uppy 를 쓰고 presigned PUT 정석 경로를 탄다. 백엔드는 URL 만 준다
- 표시용 주소도 presigned GET 이다. 버킷을 공개로 두지 않는다

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 When 사용자가 이미지를 올리면, 시스템은 아바타 자리에 그 이미지를 보여 준다
- [ ] #2 If 이미지가 아니거나 1MB 를 넘으면, then 시스템은 올리지 않는다
- [ ] #3 When 이미지를 지우면, 시스템은 기본 아바타로 되돌린다
- [ ] #4 If 이미지가 아니거나 1MB 를 넘으면, then 시스템은 사유를 알린다
<!-- AC:END -->

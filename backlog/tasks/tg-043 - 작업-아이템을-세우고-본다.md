번호는 프로젝트 안에서 평평하게 매긴다. 지운 것의 번호를 다시 쓰지 않으려면 최댓값이 아니라 다음 번호를 들고 있어야 한다.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 When 사용자가 제목을 적어 작업 아이템을 세우면, 시스템은 지금 프로젝트의 다음 번호를 매겨 그것을 세운다
- [ ] #2 When 사용자가 유형을 고르지 않고 세우면, 시스템은 Task 로 세운다
- [ ] #3 When 사용자가 본문을 적어 세우면, 시스템은 그 본문을 그대로 담는다
- [ ] #4 If 제목이 비어 있으면, then 시스템은 제목이 필요함을 알린다
- [ ] #5 [서버] When 어떤 작업 아이템을 지운 뒤 새로 세우면, 시스템은 지운 것의 번호를 다시 쓰지 않는다
- [ ] #6 When 사용자가 목록을 열면, 시스템은 지금 프로젝트의 작업 아이템만 낸다
- [ ] #7 When 사용자가 작업 아이템 하나를 열면, 시스템은 본문과 부모를 함께 낸다
- [ ] #8 [서버] If 지금 프로젝트에 없는 번호에 닿으면, then 시스템은 그 자리가 없음을 알린다
<!-- AC:END -->

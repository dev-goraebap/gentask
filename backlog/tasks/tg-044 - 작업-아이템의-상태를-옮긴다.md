## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
서술서: ITM-003 · 흐름: BF, A1, A2, A3, A4

완료와 취소가 닫힌 때를 함께 갖는다. 둘 다 더 손대지 않는 자리이기 때문이다.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 When 사용자가 작업 아이템의 상태를 옮기면, 시스템은 그 상태를 항목에 남긴다
- [ ] #2 When 사용자가 완료나 취소로 옮기면, 시스템은 그 순간을 닫힌 때로 남긴다
- [ ] #3 When 사용자가 닫힌 것을 닫히지 않은 상태로 되돌리면, 시스템은 닫힌 때를 지운다
- [ ] #4 If 옮기려는 상태가 지금 상태와 같으면, then 시스템은 아무것도 바꾸지 않는다
- [ ] #5 [서버] If 사용자의 프로젝트에 속하지 않는 항목이면, then 시스템은 그 자리가 없음을 알린다
<!-- AC:END -->

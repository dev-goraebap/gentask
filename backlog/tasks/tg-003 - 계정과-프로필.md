## Description

전달(delivery) 에픽이다. 작업 목록에 계정을 붙인다 — 가입(USR-001)과 로그인(USR-002)과 로그아웃(USR-004), 프로필과 에이전트 토큰(USR-003), 그리고 계정이 자리를 갖도록 하는 내비게이션 개편까지다.

발견 에픽을 따로 두지 않는다. 요구가 사용자에게서 확정된 형태로 왔고, 화면 탐색보다 연결이 관건이다.

## 입력

- 서술서: USR-001 · USR-002 · USR-003 · USR-004
- 인증 테이블과 세션 방식은 Webapp devkit 의 auth 모듈을 준용한다(쿠키&세션, HMAC 토큰 해시, BCrypt)
- 파일 보관은 TG-004 와 같은 presigned URL 경로를 쓴다

## 완료 조건

- TG-026 ~ TG-029 과 TG-030 · TG-031 의 인수 조건이 실제 연결로 충족된다.
- 로그인 없이 작업 API 에 닿을 수 없고, 작업은 계정 단위로 격리된다.
- 발급한 에이전트 토큰으로 Bearer 인증이 성립한다(MCP 연동 자체는 후속).

백엔드 구현은 각 Story 안에 든다. 별도 Task 로 세우지 않는다.

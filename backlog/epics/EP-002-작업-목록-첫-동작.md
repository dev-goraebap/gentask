# 작업 목록 첫 동작

전달(delivery) 에픽이다. [EP-001](EP-001-작업-목록-탐색.md)이 확정한 화면과 서술서를 실제로 동작하게 만든다. Story 는 목 위에서 화면이 돌아간다고 닫지 않고, 백엔드에 연결해 인수 조건을 충족한 시점에 닫는다.

## 입력

EP-001 이 남긴 것이다.

- 화면: 네 유스케이스의 기본 경로와 대체 경로 대부분이 목 스토어 위에 있다
- 계약 초안: `web/src/entities/task/api/task-store.ts`
- 서술서: [TSK-001](<../../docs/spec/task/TSK-001(작업 추가).md>) ~ [TSK-004](<../../docs/spec/task/TSK-004(작업 완료).md>)

## 완료 조건

- ST-001 ~ ST-013 의 인수 조건이 실제 연결로 충족된다.
- `TaskStore` 의 Http 구현이 목 구현의 자리를 대신하고, 교체가 프로바이더 하나를 바꾸는 일로 끝난다.
- 착수한 슬라이스가 걸린 서술서 미결 항목이 정해져 그 절에서 지워진다.

## 항목

순서는 [BACKLOG.md](../BACKLOG.md)가 갖는다. 여기에는 소속만 적는다.

- ST-001 ~ ST-013 (13건)

백엔드 구현은 각 Story 안에 든다. 별도 Task 로 세우지 않는다.

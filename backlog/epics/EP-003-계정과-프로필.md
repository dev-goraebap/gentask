# 계정과 프로필

전달(delivery) 에픽이다. 작업 목록에 계정을 붙인다 — 가입·로그인·로그아웃(USR-001), 프로필과 에이전트 토큰(USR-002), 그리고 계정이 자리를 갖도록 하는 내비게이션 개편까지다.

발견 에픽을 따로 두지 않는다. 요구가 사용자에게서 확정된 형태로 왔고, 화면 탐색보다 연결이 관건이다.

## 입력

- 서술서: [USR-001](<../../docs/spec/user/USR-001(계정 회원가입).md>) · [USR-002](<../../docs/spec/user/USR-002(계정 로그인).md>) · [USR-003](<../../docs/spec/user/USR-003(프로필 관리).md>) · [USR-004](<../../docs/spec/user/USR-004(계정 로그아웃).md>)
- 인증 테이블과 세션 방식은 Webapp devkit 의 auth 모듈을 준용한다(쿠키&세션, HMAC 토큰 해시, BCrypt)
- 파일 보관은 EP-004 와 같은 presigned URL 경로를 쓴다

## 완료 조건

- ST-014 ~ ST-017 의 인수 조건이 실제 연결로 충족된다.
- 로그인 없이 작업 API 에 닿을 수 없고, 작업은 계정 단위로 격리된다.
- 발급한 에이전트 토큰으로 Bearer 인증이 성립한다(MCP 연동 자체는 후속).

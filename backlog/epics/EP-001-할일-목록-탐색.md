# 할일 목록 탐색

발견(discovery) 에픽이다. 기획의 틀을 잡기 전에 네 유스케이스(적어두기 · 보기 · 손보기 · 마치기)의 화면을 목 위에 만들어 보고, 그 결과로 서술서와 API 계약을 확정한다. 전달(delivery)은 이 에픽이 닫힌 뒤 `EP-002 할일 목록 첫 동작` 이 맡는다.

## 완료 조건

- 네 유스케이스의 화면이 확정된다. 더 다듬을 것이 없다고 판단한 시점이다.
- 서술서([TK-001](<../../docs/1.analysis/작업/TK-001(할일 적어두기).md>) ~ [TK-004](<../../docs/1.analysis/작업/TK-004(할일 마치기).md>))의 흐름이 화면과 맞는다. 화면에서 바뀐 동작은 서술서에 반영되어 있다.
- `TaskStore` 인터페이스(`web/src/entities/task/api/task-store.ts`)가 API 계약 초안으로 확정된다.
- 남은 질문이 서술서의 미결 절이나 `BACKLOG.md` 의 나중 구획에 적혀 있다.

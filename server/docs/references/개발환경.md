# 개발 환경

본 문서는 서버를 빌드·실행·검사하는 방법을 정의합니다.
라이브러리 버전과 의존성의 원본은 `build.gradle`이며 이 문서가 옮겨 적지 않습니다.

## 1. 명령

| 작업 | 명령 |
|---|---|
| 개발 서버 | `./gradlew bootRun --args="--spring.profiles.active=local"` |
| 테스트 | `./gradlew test` |
| 빌드 | `./gradlew build` |
| 린트 | `./gradlew check -x test` (Checkstyle + SpotBugs + Spotless) |
| 포맷 적용 | `./gradlew spotlessApply` |

`./gradlew build`는 Docker 없이 동작합니다. Docker가 필요한 것은 통합 테스트뿐이며 Testcontainers가
1회용 PostgreSQL을 띄웁니다.

## 2. 정적 분석

코딩 표준은 산문이 아니라 설정 파일이 정의합니다 — `config/checkstyle/checkstyle.xml`과 Spotless
설정이 곧 표준입니다. 도구 선택의 근거는 [결정-0004](../decisions/결정-0004-server-정적분석-도구.md)에
있습니다.

Lombok을 어느 계층에 허용하는지처럼 **린터 설정으로 표현할 수 없는 표준**은
[결정-0023](../decisions/결정-0023-lombok-사용-범위.md)이 소유합니다.

## 3. 로컬 실행에 필요한 것

- **PostgreSQL** — 기본 접속은 `localhost:5432/devkit`입니다. `DB_URL`·`DB_USERNAME`·`DB_PASSWORD`로
  덮을 수 있습니다.
- **시크릿** — `auth.secret`은 기본값이 없어 주입하지 않으면 기동에 실패합니다([보안](보안.md) §3).
  로컬은 `src/main/resources/application-local.properties`(Git 미추적)에 두고
  `--spring.profiles.active=local`로 활성화합니다.
- **메일** — Gmail SMTP 자격증명이 없으면 발송만 실패하고 나머지는 동작합니다. OTP 코드를 직접
  읽어야 하는 검증에서는 로컬 SMTP 캐처로 돌립니다(실행 인자로 `spring.mail.*`을 덮습니다).
- **소셜 로그인** — 키를 넣지 않으면 자리표시자로 기동합니다. 키트를 복제한 사람이 소셜 없이도 바로
  실행할 수 있어야 하기 때문입니다.

## 4. 설정 값을 주입하는 세 경로

`application.properties`의 `${VAR:기본값}`은 Spring의 속성 자리표시자이며, 기본값이 없으면 반드시
주입해야 합니다. 아래로 갈수록 우선순위가 높습니다.

| 방법 | 쓰는 곳 |
|---|---|
| `application-local.properties` | 로컬 개발 (Git 미추적) |
| 환경변수 | 배포 환경 |
| 실행 인자(`--args`) | 일회성 덮어쓰기 |
